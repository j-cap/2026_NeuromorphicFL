\section{Literature Position and Novelty Boundary}
\label{sec:literature}

Federated averaging established the standard round-based architecture in which
clients perform local optimization and the server averages their model updates
\citep{mcmahan2017fedavg}. Communication-efficient learning is now a mature
field, so the contribution of Event-FedAvg cannot rest on accumulation,
thresholding, sign transmission, or event-triggered communication in isolation.
The relevant question is whether a prior method has the same complete state
transition and synchronization semantics.

\subsection{Residual, sign, and sparse compression}

One-bit SGD, signSGD, sparsified SGD with memory, and EF21 establish the central
roles of aggressive quantization and correction memory
\citep{seide2014onebit,bernstein2018signsgd,stich2018memory,richtarik2021ef21}.
Sparse ternary compression (STC) adapts residual-corrected sparsification to
both directions of federated learning \citep{sattler2019stc}. These methods
retain compression error so it can be corrected later. Strom's threshold-pulse
compressor is closer: it accumulates coordinate residuals and emits signed
fixed-amplitude pulses \citep{strom2015distributed}. Its recurrence is
conservative, however: the pulse quantum is subtracted and overshoot remains.
Event-FedAvg instead applies finite leakage, clears a fired coordinate, and
lets the server quantum follow a schedule independent of the trigger
threshold. Strom is therefore the closest algorithmic predecessor and the
mandatory nearest-neighbor comparator, but the two operators are not
equivalent.

\subsection{Event-triggered and temporal communication}

LENA accumulates a memory and self-triggers a vector upload, with server drift
representing silent workers \citep{ghadikolaei2021lena}. DETSGRAD and EventGraD
communicate a model or gradient only when an event condition is met
\citep{george2020detsgrad,ghosh2022eventgrad}. SPARQ-SGD combines a
model-deviation event with quantization and sparsification in a decentralized
network \citep{singh2023sparq}. Event-triggered FL has also been analyzed with
both upstream and downstream triggers, and later work adapts thresholds to
balance client traffic \citep{he2023etfl,yoon2025etfl}. A 2026 gossip method
continues this line with decentralized model-deviation triggers
\citep{zhai2026gossip}. Across these methods, the communicated object is a
model, gradient, or compressed change; none of the inspected transitions
combines leaky coordinate evidence, first-passage sign pulses, full reset, and
an independent applied quantum. Level-crossing distributed estimation remains
a useful event-time/sign coding analogy, but it is not an FL optimizer or
synchronization protocol \citep{utlu2017level}.

\subsection{Federated spiking neural networks}

Federated SNN research uses spikes and LIF state inside the predictive model.
Representative methods federate SNN weights, study masking and client dropout,
or fuse heterogeneous SNNs through firing-rate information
\citep{venkatesha2021fedsnn,chaki2023tradeoffs,tao2026sfedhifi}. Event-FedAvg
instead leaves the trained MLP or CNN conventional and places LIF-inspired
dynamics at the communication layer. Consequently, the project does not claim
to be the first neuromorphic or event-triggered FL method.

\subsection{Defensible novelty statement}

The literature search frozen on 2026-09-04 did not identify a predecessor with
the complete operator: weighted local FedAvg deltas drive persistent leaky
coordinate states; a first-passage event transmits only sign and address;
firing fully clears the state and discards overshoot; an independently
scheduled model quantum is aggregated algebraically without second client
weighting; and ordered sparse replay with dense-checkpoint fallback provides
exact catch-up. This is a qualified search result rather than a proof of
universal priority. The search must be repeated before submission. The full
operator table, query families, and manuscript language constraints are
recorded in \texttt{paper/ijcnn2027/RELATED\_WORK.md}.
