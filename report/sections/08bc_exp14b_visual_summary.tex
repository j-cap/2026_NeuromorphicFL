\subsection{Visual summary of partition-sensitive class convergence}

The independent-partition results in Table~\ref{tab:exp14b-seeds} are easier to interpret when the weakest class is viewed directly across partitions. Figure~\ref{fig:exp14b-seed-worst} therefore isolates the worst-class metric for the event method, EF-TopK, and dense SGD. The plot makes two points visually explicit: the event method is competitive on seeds 2400 and 2600, while seed 2500 contains a pronounced finite-horizon class transient that aggregate accuracy alone would obscure. This observation motivates the event-share and compute-heterogeneity mechanism audit in Experiment~14C.
