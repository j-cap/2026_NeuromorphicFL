\section{Consolidation Question Q3: Compatibility with FedAvg-Style Local Training}
\label{sec:consolidation-q3}

Q3 asks whether frozen V1 is a communication layer for federated learning or whether it is tied to the asynchronous FedSGD-like setting used in most of Part~I. The decisive change is to replace the one-step stochastic-gradient signal by a conventional local model delta generated after several client-side SGD steps. This is the compatibility test required before describing the method as a general FL communication mechanism.

\subsection{Event-FedAvg formulation}

The study starts from synchronous full-participation FedAvg~\cite{mcmahan2017fedavg} so that local training is the only new variable. At round $r$, all clients receive the same server model $w^r$. Client $i$ initializes
\begin{equation}
    w_{i,0}^r=w^r
\end{equation}
and performs $E$ local stochastic-gradient steps,
\begin{equation}
    w_{i,e+1}^r
    =w_{i,e}^r-\eta\nabla\ell_i(w_{i,e}^r;\xi_{i,e}),
    \qquad e=0,\ldots,E-1.
\end{equation}
The local FedAvg update is
\begin{equation}
    \Delta_i^r=w_{i,E}^r-w^r.
    \label{eq:q3-local-delta}
\end{equation}
For Event-FedAvg, the encoder input is exactly this model delta rather than a separately recomputed gradient.

A deterministic scale conversion connects the delta representation to the gradient-evidence interpretation used in Part~I. For equal-size clients with aggregation weight $p_i$,
\begin{equation}
    \boxed{
    z_i^{r+1}
    =\rho z_i^r
    +\frac{p_i}{\eta}\Delta_i^r.
    }
    \label{eq:q3-event-fedavg-state}
\end{equation}
Since
\begin{equation}
    \Delta_i^r
    \approx
    -\eta\sum_{e=0}^{E-1}g_{i,e}^r,
\end{equation}
Equation~\eqref{eq:q3-event-fedavg-state} approximately accumulates
\begin{equation}
    -p_i\sum_{e=0}^{E-1}g_{i,e}^r.
\end{equation}
The factor $1/\eta$ is therefore a unit conversion, not an $E$-specific rescue parameter. In particular, the signal is not divided by $E$. Increasing local work is allowed to produce more accumulated evidence.

The communication rule is unchanged. Coordinate $j$ fires when
\begin{equation}
    |z_{ij}^{r+1}|\geq\Delta,
\end{equation}
transmits its coordinate address and sign,
\begin{equation}
    (j,s_{ij}),\qquad s_{ij}=\operatorname{sign}(z_{ij}^{r+1}),
\end{equation}
then undergoes full reset,
\begin{equation}
    z_{ij}^{r+1}\leftarrow0.
\end{equation}
The server applies
\begin{equation}
    w_j^+=w_j+q_r s_{ij}.
\end{equation}
Thus Q3 changes only the source of the learning signal. The stateful threshold/reset communication operator identified in Q1 remains intact.

\subsection{Experimental design and fair local-optimizer selection}

The primary benchmark is the ten-class Fashion-MNIST MLP from Experiment~14B with architecture
\begin{equation}
    784\rightarrow32\rightarrow16\rightarrow10,
\end{equation}
and $d=25818$ trainable parameters. The same strong non-IID partition with seed 2400 is used. All ten clients participate in every synchronous round.

The local-work sweep is
\begin{equation}
    E\in\{1,5,10\}.
\end{equation}
For each $E$, dense FedAvg first audits
\begin{equation}
    \eta\in\{0.01,0.02,0.05,0.1\}
\end{equation}
using the final training objective. The selected value is
\begin{equation}
    \boxed{\eta=0.1}
\end{equation}
for all three settings. This value is then frozen for every communication method.

A short communication-side event audit tests only a small neighborhood of the established V1 scale. The selected MLP configuration is
\begin{equation}
    \rho=0.999,
    \qquad
    \Delta=0.025,
    \qquad
    q_r=0.005(1+r/100)^{-0.1}.
    \label{eq:q3-selected-v1}
\end{equation}
It is used without $E$-dependent retuning in the final 150-round comparison.

The matched baselines are
\begin{enumerate}
    \item dense FedAvg,
    \item FedAvg with EF-TopK at 0.5\% sparsity,
    \item FedAvg with EF-TopK at 2.5\% sparsity,
    \item dense sign compression with one float32 scale and error feedback,
    \item Event-FedAvg.
\end{enumerate}
All methods use the same client initialization, minibatch size, local SGD step, client data, and number of local steps.

The latter statement should not be interpreted as proof that event compression intrinsically improves FedAvg optimization. Event-FedAvg contains an independently scheduled model quantum $q_r$, while dense FedAvg applies the averaged delta directly. The purpose of Q3 is compatibility and communication efficiency, not a claim that compression must improve generalization. A publication-level comparison should retain matched tuning budgets for all final baselines.

\subsection{The $E=1$ bridge is weaker but not contradictory}

At $E=1$, Event-FedAvg reaches 71.93\% accuracy compared with 74.84\% for dense FedAvg after 150 rounds. It nevertheless gives lower test CE than the 2.5\% EF-TopK baseline while using about $5.5\times$ less payload. This is a qualified rather than dominant result.

The pattern is scientifically useful. V1 does not become unstable as local work increases. Instead, its relative performance improves when the encoder is driven by a genuine multi-step local delta. This is consistent with the intended temporal-evidence interpretation: a local FedAvg update already integrates several stochastic learning signals before entering the persistent communication state.

Consequently the supported claim is deliberately limited to compatibility rather than universal dominance.
\begin{takeawaybox}[title={Q3 compatibility conclusion}]
V1 is compatible with conventional multi-step FedAvg local updates. The evidence does not support the stronger claim that one fixed event setting dominates dense FedAvg for every amount of local work and every horizon.
\end{takeawaybox}
The evidence does not support a stronger statement that one fixed event setting uniformly dominates dense FedAvg for every $E$ and horizon.

\subsection{Compact-CNN transfer}

The strong-pass criterion additionally requires one architecture transfer. The compact CNN from Experiment~15A is therefore tested at $E=5$. A method-neutral dense audit over
\begin{equation}
    \eta\in\{0.02,0.05,0.08,0.1\}
\end{equation}
again selects $\eta=0.1$. The event audit varies only $q_0\in\{0.005,0.0075,0.01\}$ with $\Delta=0.025$, $\rho=0.999$, and exponent $0.3$. The best training-objective setting uses $q_0=0.01$.

\subsection{Q3 decision and impact on the frozen method}

The pre-registered minimum gate requires a clear pass at $E=5$. The strong gate requires the conclusion to persist at $E=10$ and transfer to the compact CNN. All three conditions are satisfied.

The Q3 verdict is therefore
\begin{equation}
\boxed{\text{Q3 FedAvg compatibility: STRONG PASS}.}
\end{equation}

The main algorithmic consequence is that the standard FL presentation of V1 should now use a local model delta as the generic client update source:
\begin{equation}
\boxed{
\Delta_i^r=w_{i,E}^r-w^r,
\qquad
z_i^{r+1}=\rho z_i^r+\frac{p_i}{\eta}\Delta_i^r.
}
\end{equation}
The earlier stochastic-gradient formulation remains a special case useful for asynchronous analysis, but the communication layer is not restricted to that setting.

This result also makes Q2 structurally compatible with the final method. Q2 operates on the ordered sparse server-update packets after compression, so the same replay/checkpoint protocol can be attached to Event-FedAvg. A final publication-level baseline campaign should combine the Q3 client-update semantics with Q2 bidirectional accounting and include the closest Q1 predecessor. That is a baseline-completeness task rather than an unresolved compatibility question.
