\section{Research Roadmap}

\subsection{Completed mechanism diagnostics}

The first seven experiments now establish the following progression:
\begin{enumerate}
  \item stationary stochastic quadratic: temporal accumulation improves signed-event reliability and strongly reduces communication relative to periodic sign updates in the toy setting;
  \item large moving optimum: residual membrane evidence is present but is rapidly overwhelmed by a strong new gradient;
  \item moderate moving optimum after stationary convergence: leakage does not improve tracking and mainly reduces communication at the cost of slower adaptation;
  \item controlled stale membrane: leakage erases an opposing membrane sign faster but does not reduce the total first-passage time to a useful threshold event, and sufficiently strong leakage creates a deadzone;
  \item controlled asynchronous model drift: the same distinction holds when the objective is fixed and the gradient changes only because the server model moves;
  \item endogenous two-client asynchronous learning: a selected noisy operating point shows a net benefit for mild finite memory, initially suggesting soft stale-evidence invalidation;
  \item asynchrony--memory regime map: the finite-memory optimum remains approximately $\rho=0.99$ for every tested compute-rate ratio, including $R=1$, and disappears entirely in a zero-noise control. This falsifies the strong claim that the observed gain is primarily caused by asynchronous stale-evidence handling in the homogeneous problem.
\end{enumerate}

The current interpretation of leak must therefore be narrower than initially hoped. The strongest supported role is
\begin{equation}
  \boxed{\text{stochastic temporal-evidence filtering and communication regularization}.}
\end{equation}
A genuinely federated freshness benefit remains a hypothesis to be tested under local-objective heterogeneity, where remote model motion can reverse a particular client's current gradient direction.

\subsection{Immediate next experiments}

\begin{enumerate}
  \item \textbf{Heterogeneous asynchronous quadratics with rate normalization.} Use
  \begin{equation}
    F_i(w)=\frac12(w-\theta_i)^2
  \end{equation}
  with controlled local optima. Choose configurations in which fast-client updates can move $w$ across the slow client's local optimum while its membrane still stores evidence from the opposite side. Because unequal compute rates otherwise implicitly overweight fast clients, introduce an explicit client/rate weighting rule so the intended aggregate objective
  \begin{equation}
    F(w)=\sum_i p_iF_i(w)
  \end{equation}
  remains well defined independently of hardware speed.

  Measure two event labels separately:
  \begin{enumerate}
    \item locally stale: event sign disagrees with the client's \emph{current} exact local gradient;
    \item globally harmful: the event increases the intended aggregate objective.
  \end{enumerate}
  This is now the decisive experiment for an FL-specific memory claim.

  \item \textbf{Noise--memory map.} Since Experiment~7 identifies noise filtering as the main supported finite-memory mechanism, explicitly sweep $\sigma$ against $\rho$. Determine how the optimal memory horizon changes with stochastic-gradient signal-to-noise ratio and whether that behavior can be predicted from the scalar OU/LIF analysis.

  \item \textbf{Memory/threshold map.} Systematically map $(\rho,\Delta,q,\gamma)$ to optimization error, event rate, wrong/harmful-event probability, and deadzone behavior. Separate the evidence threshold $\Delta$ from the update quantum $q$ throughout.

  \item \textbf{Random asynchronous schedules and delay.} Replace deterministic periods by Poisson or renewal computation times and introduce communication latency only after the heterogeneous deterministic case is understood.

  \item \textbf{Vector quadratic.} Move from one coordinate to diagonal and then coupled quadratics. Study coordinate addressing, simultaneous threshold crossings, gradient correlation, and whether per-coordinate or blockwise LIF memory is preferable.

  \item \textbf{Block/event coding.} Compare one membrane per coordinate with blockwise norms or structured groups. This is required before neural networks because coordinate addresses may otherwise dominate the bit budget.
\end{enumerate}

\subsection{Theory milestones}

A useful theoretical progression is:
\begin{enumerate}
  \item deterministic scalar hybrid model and practical-convergence bound;
  \item stochastic scalar first-passage analysis and expected descent;
  \item explicit noise--memory design rule for the LIF evidence state;
  \item asynchronous heterogeneous quadratic with rate-corrected client weighting and stale-sign conditions;
  \item vector strongly convex objective with coordinatewise or blockwise event encoders;
  \item stochastic smooth objective with bounded variance and asynchronous updates;
  \item multi-client objective $F=\sum_i p_iF_i$ with bounded heterogeneity, computation-rate mismatch, and communication delay;
  \item nonconvex neural-network setting.
\end{enumerate}

The theoretical quantities should mirror the control perspective where useful: Lyapunov/objective decrease, practical convergence neighborhood, event-rate bounds, robustness to noisy inputs, communication-deadzone conditions, and the relationship between evidence memory and the timescale on which the gradient signal itself changes. The previously proposed direct relation
\begin{equation}
  \tau_{\mathrm{mem}}\sim\tau_{\mathrm{remote\ model\ change}}
\end{equation}
should no longer be assumed; Experiment~7 shows that it is not supported in the homogeneous scalar setting.

\subsection{Federated prototype}

The first broader federated prototype should still use a convex/vector objective before MNIST or CIFAR. Each client maintains its own membrane state and generates asynchronous signed coordinate or block events. Required baselines include local SGD/FedAvg, periodic sign methods, an error-feedback compressor, a sparsification method, event-triggered/lazy distributed learning, IF with infinite memory, and explicit reset/invalidation strategies.

The main performance axes should be
\begin{equation}
  \text{optimization/test error versus transmitted bits}
\end{equation}
and
\begin{equation}
  \text{optimization/test error versus communication events},
\end{equation}
not accuracy versus nominal rounds. Actual encoding cost must include coordinate or block addresses and protocol overhead; an event is not literally one bit merely because its signed amplitude is binary.

An additional fairness axis is now required:
\begin{equation}
  \text{per-client participation versus compute rate}.
\end{equation}
Experiment~7 shows that communication reduction can result from effectively silencing slow clients. Any heterogeneous-data experiment must detect and penalize this failure mode.

\subsection{Neural-network experiment}

Only after the asynchronous convex prototype survives the heterogeneous/rate-normalized tests should an ordinary neural network be introduced. Backpropagation produces conventional stochastic gradients; the LIF bank acts after gradient computation as the communication encoder. Candidate benchmarks are a small MLP/CNN on MNIST followed by a modest CIFAR-10 model. The goal is not initially state-of-the-art accuracy, but to establish whether temporal evidence and event-driven communication survive realistic high-dimensional, noisy, non-IID gradients.

\subsection{Paper-level decision criteria}

The project should proceed toward a paper only if at least one of the following stronger claims survives comparison with existing methods:
\begin{itemize}
  \item LIF/IF temporal evidence gives a better communication--reliability trade-off than periodic sign and standard error-feedback compression under stochastic gradients;
  \item a finite memory horizon provides a robust advantage under \emph{true heterogeneous asynchronous model drift} after correcting for compute-rate bias;
  \item the hybrid-system formulation yields new convergence, event-rate, deadzone, or memory/noise design rules unavailable from standard compression analysis;
  \item asynchronous event timing itself provides a systems-level benefit under heterogeneous client computation and communication rates without silencing slow clients;
  \item bidirectional event-coded model evolution materially reduces communication while preserving useful learning behavior.
\end{itemize}

If none of these survives systematic sweeps and modern baselines, the project should be reframed as an interpretation of existing error-feedback/event-triggered optimization rather than forced into a novelty claim.

\subsection{Working name}

The repository and umbrella project are named \texttt{NeuromorphicFL}. A future algorithm name can be introduced only after the mechanism stabilizes; \emph{LIF-SGD} is currently a descriptive working name rather than a claimed new method name.
