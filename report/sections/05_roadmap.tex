\section{Research Roadmap}

\subsection{Completed mechanism diagnostics}

The first eight experiments now establish the following progression:
\begin{enumerate}
  \item stationary stochastic quadratic: temporal accumulation improves signed-event reliability and strongly reduces communication relative to periodic sign updates in the toy setting;
  \item large moving optimum: residual membrane evidence is present but is rapidly overwhelmed by a strong new gradient;
  \item moderate moving optimum after stationary convergence: leakage does not improve tracking and mainly reduces communication at the cost of slower adaptation;
  \item controlled stale membrane: leakage erases an opposing membrane sign faster but does not reduce the total first-passage time to a useful threshold event, and sufficiently strong leakage creates a deadzone;
  \item controlled asynchronous model drift: the same distinction holds when the objective is fixed and the gradient changes only because the server model moves;
  \item endogenous two-client asynchronous learning: a selected noisy operating point shows a net benefit for mild finite memory, initially suggesting soft stale-evidence invalidation;
  \item asynchrony--memory regime map: the finite-memory optimum remains approximately $\rho=0.99$ for every tested compute-rate ratio, including $R=1$, and disappears entirely in a zero-noise homogeneous control. This falsifies the strong claim that the observed gain is primarily caused by asynchronous stale-evidence handling in the homogeneous problem;
  \item heterogeneous delayed-gradient federation with rate normalization: true computation-delay staleness is introduced explicitly and can produce locally stale, globally harmful events under strong delay. However, a fresh-gradient oracle removes these stale events without materially improving IF, while LIF also improves in regimes where stale events are absent. Thus the dominant LIF gain in the scalar heterogeneous test is broader event regularization/deadzone behavior rather than a robust FL-specific freshness mechanism.
\end{enumerate}

The current interpretation of leak should therefore be explicit and conservative. The strongest supported roles are
\begin{equation}
  \boxed{\text{stochastic temporal-evidence filtering + event/communication regularization}.}
\end{equation}
Finite memory also creates a practical deadzone that can suppress persistent locally motivated but globally conflicting events under heterogeneous objectives. Whether that is useful beyond standard damping, deadband, proximal regularization, or server-side event rejection is now the more relevant question. A genuinely distinctive FL-specific stale-gradient advantage of leak has \emph{not} been demonstrated in the scalar studies.

\subsection{Immediate next experiments}

\begin{enumerate}
  \item \textbf{Mechanism comparator study for heterogeneous event suppression.} Experiment~8 shows that mild LIF can reduce globally harmful heterogeneous events even when stale events are absent, but this cannot yet be attributed specifically to the neuromorphic leak. Compare LIF against simpler mechanisms that can produce similar behavior:
  \begin{itemize}
    \item explicit server deadband / event rejection based on aggregate objective or a surrogate thereof;
    \item decaying learning-rate or event-quantum schedules;
    \item local proximal pull toward the current global model;
    \item hard reset and partial membrane reset after remote updates;
    \item conventional exponential moving-average gradient filtering without event timing;
    \item error-feedback / residual compression baselines with matched memory.
  \end{itemize}
  The purpose is to determine whether LIF offers a distinct communication--accuracy trade-off or merely instantiates standard regularization in hybrid form.

  \item \textbf{Noise--memory map.} Experiment~7 and the noisy part of Experiment~8 identify noise filtering as the main robust finite-memory mechanism. Explicitly sweep $\sigma$ against $\rho$ and test whether the optimal memory horizon can be predicted from the scalar OU/LIF analysis. The desired result is not just an empirical optimum but a design rule linking gradient SNR, evidence threshold, and memory horizon.

  \item \textbf{Memory/threshold/update-quantum map.} Systematically map $(\rho,\Delta,q,\gamma)$ to optimization error, event rate, wrong/harmful-event probability, and deadzone behavior. Separate the evidence threshold $\Delta$ from the update quantum $q$ throughout. The current heterogeneous stress study shows that favorable results can depend on the relation between local-optimum separation and event quantum; this dependence must be mapped rather than hidden.

  \item \textbf{Random asynchronous schedules and delay.} Replace deterministic compute periods by Poisson or renewal computation times and add communication latency. This should be done only after the mechanism comparator clarifies whether finite-memory event regularization is worth carrying forward.

  \item \textbf{Vector quadratic.} Move from one coordinate to diagonal and then coupled quadratics. Study coordinate addressing, simultaneous threshold crossings, gradient correlation, and whether per-coordinate or blockwise LIF memory is preferable.

  \item \textbf{Block/event coding.} Compare one membrane per coordinate with blockwise norms or structured groups. This is required before neural networks because coordinate addresses may otherwise dominate the bit budget.
\end{enumerate}

\subsection{Theory milestones}

A useful theoretical progression is:
\begin{enumerate}
  \item deterministic scalar hybrid model and practical-convergence bound;
  \item stochastic scalar first-passage analysis and expected descent;
  \item explicit noise--memory design rule for the LIF evidence state;
  \item characterization of the finite-memory deadzone and the event-suppression effect under opposing heterogeneous local gradients;
  \item comparison/equivalence results between LIF memory, exponential residual decay, error-feedback memory decay, and simpler deadband mechanisms;
  \item vector strongly convex objective with coordinatewise or blockwise event encoders;
  \item stochastic smooth objective with bounded variance and asynchronous updates;
  \item multi-client objective $F=\sum_i p_iF_i$ with bounded heterogeneity, computation-rate mismatch, and communication delay;
  \item nonconvex neural-network setting.
\end{enumerate}

The theoretical quantities should mirror the control perspective where useful: Lyapunov/objective decrease, practical convergence neighborhood, event-rate bounds, robustness to noisy inputs, communication-deadzone conditions, and the relationship between evidence memory and the timescale on which the gradient signal itself changes. The previously proposed direct relation
\begin{equation}
  \tau_{\mathrm{mem}}\sim\tau_{\mathrm{remote\ model\ change}}
\end{equation}
should not be assumed; Experiments~7--8 do not support it as a general explanation of the observed finite-memory benefit.

\subsection{Federated prototype}

The first broader federated prototype should still use a convex/vector objective before MNIST or CIFAR. Each client maintains its own membrane state and generates asynchronous signed coordinate or block events. Required baselines include local SGD/FedAvg, periodic sign methods, an error-feedback compressor, a sparsification method, event-triggered/lazy distributed learning, IF with infinite memory, explicit reset/invalidation strategies, and the simpler deadband/proximal/EMA comparators motivated by Experiment~8.

The main performance axes should be
\begin{equation}
  \text{optimization/test error versus transmitted bits}
\end{equation}
and
\begin{equation}
  \text{optimization/test error versus communication events},
\end{equation}
not accuracy versus nominal rounds. Actual encoding cost must include coordinate or block addresses and protocol overhead; an event is not literally one bit merely because its signed amplitude is binary.

Two additional fairness axes are required:
\begin{equation}
  \text{per-client participation versus compute rate}
\end{equation}
and
\begin{equation}
  \text{effective client contribution versus intended weight }p_i.
\end{equation}
Experiments~7--8 show why both matter: finite memory can suppress slow clients, while unequal compute rates can otherwise redefine the aggregate objective implicitly. Rate normalization must therefore be part of the algorithmic specification rather than an afterthought.

\subsection{Neural-network experiment}

Only after the convex/vector prototype survives the mechanism-comparator tests should an ordinary neural network be introduced. Backpropagation produces conventional stochastic gradients; the LIF bank acts after gradient computation as the communication encoder. Candidate benchmarks are a small MLP/CNN on MNIST followed by a modest CIFAR-10 model. The goal is not initially state-of-the-art accuracy, but to establish whether temporal evidence and event-driven communication survive realistic high-dimensional, noisy, non-IID gradients and remain competitive with modern compression/error-feedback baselines.

\subsection{Paper-level decision criteria}

The project should proceed toward a paper only if at least one of the following stronger claims survives comparison with existing methods:
\begin{itemize}
  \item LIF/IF temporal evidence gives a better communication--reliability trade-off than periodic sign and standard error-feedback compression under stochastic gradients;
  \item the hybrid-system formulation yields a useful noise--memory or event-rate design law that is not obvious from standard compression analysis;
  \item finite-memory event suppression under heterogeneous clients outperforms simpler deadband, proximal, EMA, or reset mechanisms at matched communication and accuracy;
  \item asynchronous event timing itself provides a systems-level benefit under heterogeneous client computation and communication rates without silencing slow clients or distorting intended client weights;
  \item bidirectional event-coded model evolution materially reduces communication while preserving useful learning behavior.
\end{itemize}

A direct claim that LIF is valuable because it fixes stale asynchronous FL gradients is no longer supported by the current scalar evidence and should not be used as the core paper story unless a later, substantially different setting overturns Experiments~7--8.

If none of the remaining claims survives systematic sweeps and modern baselines, the project should be reframed as an interpretation of existing error-feedback/event-triggered optimization rather than forced into a novelty claim.

\subsection{Working name}

The repository and umbrella project are named \texttt{NeuromorphicFL}. A future algorithm name can be introduced only after the mechanism stabilizes; \emph{LIF-SGD} is currently a descriptive working name rather than a claimed new method name.
