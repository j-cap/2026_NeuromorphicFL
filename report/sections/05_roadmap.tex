\section{Research Roadmap}

\subsection{Completed mechanism diagnostics}

The first four experiments now establish the basic scalar picture:
\begin{enumerate}
  \item stationary stochastic quadratic: temporal accumulation improves signed-event reliability and strongly reduces communication relative to periodic sign updates in the toy setting;
  \item large moving optimum: residual membrane evidence is present but is rapidly overwhelmed by a strong new gradient;
  \item moderate moving optimum after stationary convergence: once the change-point state is controlled, leakage does not improve tracking and mainly reduces communication at the cost of slower adaptation;
  \item controlled stale membrane: leakage erases an opposing membrane sign faster but does not reduce the total first-passage time to a useful threshold event, and sufficiently strong leakage creates a deadzone.
\end{enumerate}

These findings narrow the role of leak. It should not currently be motivated as a generic mechanism for faster adaptation to changing objectives. Its defensible roles are finite memory, noise/chatter suppression, and explicit regulation of the communication--responsiveness trade-off.

\subsection{Immediate next experiments}

The next experiments should remain deliberately small and mechanism-focused.
\begin{enumerate}
  \item \textbf{Parameter map.} Systematically map $(q,\Delta,\rho,\sigma)$ to optimization error, wrong-event probability, event rate, transient response, and deadzone behavior. Separate the roles of update resolution, evidence threshold, gradient-noise level, and memory horizon.
  \item \textbf{Vector quadratic.} Move from one coordinate to a diagonal and then coupled quadratic. Study coordinate addressing, simultaneous threshold crossings, correlations between gradient coordinates, and whether coordinatewise LIF states remain sensible at high dimension.
  \item \textbf{Asynchronous-model-drift diagnostic.} Instead of externally changing the objective, let a local LIF encoder accumulate gradients while an external process moves the model parameter, mimicking updates generated by other clients. This is the setting in which finite memory could plausibly protect against genuinely stale local evidence. Compare IF, LIF, and explicit residual reset/reprojection strategies.
  \item \textbf{Block/event coding.} Compare one membrane per coordinate with blockwise norms or structured groups. This is required before neural networks because coordinate addresses may otherwise dominate the bit budget.
\end{enumerate}

\subsection{Theory milestones}

A useful theoretical progression is:
\begin{enumerate}
  \item deterministic scalar hybrid model and practical-convergence bound;
  \item stochastic scalar first-passage analysis and expected descent;
  \item vector strongly convex objective with coordinatewise or blockwise event encoders;
  \item stochastic smooth objective with bounded variance;
  \item asynchronous multi-client objective $F=\sum_i p_iF_i$ with bounded heterogeneity and model staleness;
  \item nonconvex neural-network setting.
\end{enumerate}

The theoretical quantities should mirror the control perspective where useful: Lyapunov/objective decrease, practical convergence neighborhood, inter-event time or event-rate bounds, robustness to noisy inputs, and explicit conditions for a communication deadzone.

\subsection{Federated prototype}

The first federated prototype should use a small number of clients and a convex/vector objective before MNIST or CIFAR. Each client maintains its own membrane state and generates asynchronous signed coordinate or block events. Required baselines include FedAvg/local SGD, periodic sign methods, an error-feedback compressor, a sparsification method, and an event-triggered/lazy distributed-learning method.

The main performance axes should be
\begin{equation}
  \text{optimization/test error versus transmitted bits},
\end{equation}
and
\begin{equation}
  \text{optimization/test error versus communication events},
\end{equation}
not accuracy versus nominal rounds. Actual encoding cost must include coordinate or block addresses and protocol overhead; an event is not literally one bit merely because its signed amplitude is binary.

The first multi-client experiment should also isolate the genuinely federated source of staleness: while client $i$ accumulates local evidence, server updates caused by clients $j\neq i$ move the model. This differs from Experiments 2--4, where the objective or membrane was changed exogenously.

\subsection{Neural-network experiment}

Only after the federated convex prototype is understood should an ordinary neural network be introduced. Backpropagation produces conventional stochastic gradients; the LIF bank acts after gradient computation as the communication encoder. Candidate benchmarks are a small MLP/CNN on MNIST followed by a modest CIFAR-10 model. The goal is not initially state-of-the-art accuracy, but to establish whether the temporal-evidence mechanism survives realistic high-dimensional, noisy, non-IID gradients.

\subsection{Paper-level decision criteria}

The project should proceed toward a paper only if at least one of the following stronger claims survives comparison with existing methods:
\begin{itemize}
  \item LIF/IF temporal evidence gives a better communication--reliability trade-off than periodic sign and standard error-feedback compression under stochastic gradients;
  \item finite memory provides a demonstrable net advantage under true asynchronous model drift, despite the deadzone and slower-evidence-accumulation costs observed in the scalar tests;
  \item the hybrid-system formulation yields new convergence/event-rate/deadzone guarantees or design rules unavailable from standard compression analysis;
  \item asynchronous event timing itself provides a systems-level benefit under heterogeneous client computation/communication rates;
  \item bidirectional event-coded model evolution materially reduces communication while preserving useful learning behavior.
\end{itemize}

If none of these survives, the project should be reframed as an interpretation of existing error-feedback/event-triggered optimization rather than forced into a novelty claim.

\subsection{Working name}

The repository and umbrella project are named \texttt{NeuromorphicFL}. A future algorithm name can be introduced only after the mechanism stabilizes; \emph{LIF-SGD} is currently a descriptive working name rather than a claimed new method name.
