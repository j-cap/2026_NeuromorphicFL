\section{Research Roadmap}

\subsection{Completed mechanism diagnostics}

The first six experiments now establish the following progression:
\begin{enumerate}
  \item stationary stochastic quadratic: temporal accumulation improves signed-event reliability and strongly reduces communication relative to periodic sign updates in the toy setting;
  \item large moving optimum: residual membrane evidence is present but is rapidly overwhelmed by a strong new gradient;
  \item moderate moving optimum after stationary convergence: leakage does not improve tracking and mainly reduces communication at the cost of slower adaptation;
  \item controlled stale membrane: leakage erases an opposing membrane sign faster but does not reduce the total first-passage time to a useful threshold event, and sufficiently strong leakage creates a deadzone;
  \item controlled asynchronous model drift: the same conclusion holds when the objective is fixed and the gradient changes only because the server model moves;
  \item endogenous two-client asynchronous learning: mild leakage can reduce stale/harmful events and improve the communication--accuracy trade-off, whereas both infinite memory and aggressive forgetting/hard reset can be inferior.
\end{enumerate}

These findings substantially sharpen the role of leak. It should not be motivated as a generic mechanism for faster adaptation. The strongest current interpretation is instead as a \emph{soft evidence-freshness mechanism}: old evidence is discounted continuously, but persistent gradients can still accumulate. This potentially balances two undesirable extremes---IF's infinite memory and hard residual invalidation after every remote update.

\subsection{Immediate next experiments}

The next work should stress-test whether the favorable two-client result is structural or a tuned scalar effect.
\begin{enumerate}
  \item \textbf{Asynchrony map.} Sweep the slow/fast compute-rate ratio, gradient-noise level, and random client phases. Measure harmful-event fraction, tail error, and communication for IF, hard reset, and LIF. The central question is whether an intermediate memory horizon remains optimal across a meaningful region rather than at one selected operating point.
  \item \textbf{Memory/threshold map.} Systematically map $(\rho,\Delta,q,\gamma)$ to optimization error, event rate, stale-event probability, and deadzone behavior. The effective memory timescale should be compared with the characteristic time between remote server updates.
  \item \textbf{Statistical heterogeneity.} Replace homogeneous client objectives by
  \begin{equation}
    F_i(w)=\frac12(w-\theta_i)^2
  \end{equation}
  with controlled spreads in $\theta_i$. Distinguish an event that is stale relative to the client's current gradient from an event that is globally harmful; these notions no longer coincide under non-IID objectives.
  \item \textbf{Random asynchronous schedules and delay.} Replace deterministic periods by Poisson or renewal computation times and introduce communication latency. This will test whether wall-clock LIF memory remains meaningful under realistic irregularity.
  \item \textbf{Vector quadratic.} Move from one coordinate to diagonal and then coupled quadratics. Study coordinate addressing, simultaneous threshold crossings, gradient correlation, and whether per-coordinate or blockwise LIF memory is preferable.
  \item \textbf{Block/event coding.} Compare one membrane per coordinate with blockwise norms or structured groups. This is required before neural networks because coordinate addresses may otherwise dominate the bit budget.
\end{enumerate}

\subsection{Theory milestones}

A useful theoretical progression is:
\begin{enumerate}
  \item deterministic scalar hybrid model and practical-convergence bound;
  \item stochastic scalar first-passage analysis and expected descent;
  \item asynchronous two-client quadratic with explicit model-drift and memory-timescale analysis;
  \item vector strongly convex objective with coordinatewise or blockwise event encoders;
  \item stochastic smooth objective with bounded variance and asynchronous updates;
  \item multi-client objective $F=\sum_i p_iF_i$ with bounded heterogeneity, computation-rate mismatch, and communication delay;
  \item nonconvex neural-network setting.
\end{enumerate}

The theoretical quantities should mirror the control perspective where useful: Lyapunov/objective decrease, practical convergence neighborhood, event-rate bounds, robustness to noisy inputs, conditions for harmful stale events, and explicit communication-deadzone conditions. A particularly important design target is a relationship between the LIF memory timescale
\begin{equation}
  \tau_{\mathrm{mem}}\sim\frac{1}{1-\rho}
\end{equation}
and the characteristic timescale on which remote clients move the global model.

\subsection{Federated prototype}

The first broader federated prototype should still use a convex/vector objective before MNIST or CIFAR. Each client maintains its own membrane state and generates asynchronous signed coordinate or block events. Required baselines include local SGD/FedAvg, periodic sign methods, an error-feedback compressor, a sparsification method, event-triggered/lazy distributed learning, IF with infinite memory, and explicit reset/invalidation strategies.

The main performance axes should be
\begin{equation}
  \text{optimization/test error versus transmitted bits},
\end{equation}
and
\begin{equation}
  \text{optimization/test error versus communication events},
\end{equation}
not accuracy versus nominal rounds. Actual encoding cost must include coordinate or block addresses and protocol overhead; an event is not literally one bit merely because its signed amplitude is binary.

\subsection{Neural-network experiment}

Only after the asynchronous convex prototype survives parameter sweeps should an ordinary neural network be introduced. Backpropagation produces conventional stochastic gradients; the LIF bank acts after gradient computation as the communication encoder. Candidate benchmarks are a small MLP/CNN on MNIST followed by a modest CIFAR-10 model. The goal is not initially state-of-the-art accuracy, but to establish whether temporal evidence, soft freshness, and event-driven participation survive realistic high-dimensional, noisy, non-IID gradients.

\subsection{Paper-level decision criteria}

The project should proceed toward a paper only if at least one of the following stronger claims survives comparison with existing methods:
\begin{itemize}
  \item LIF/IF temporal evidence gives a better communication--reliability trade-off than periodic sign and standard error-feedback compression under stochastic gradients;
  \item an intermediate finite memory horizon provides a robust advantage under true asynchronous model drift by reducing stale/harmful events without the evidence destruction caused by hard reset;
  \item the hybrid-system formulation yields new convergence, event-rate, deadzone, or memory-timescale design rules unavailable from standard compression analysis;
  \item asynchronous event timing itself provides a systems-level benefit under heterogeneous client computation and communication rates;
  \item bidirectional event-coded model evolution materially reduces communication while preserving useful learning behavior.
\end{itemize}

If none of these survives systematic sweeps and modern baselines, the project should be reframed as an interpretation of existing error-feedback/event-triggered optimization rather than forced into a novelty claim.

\subsection{Working name}

The repository and umbrella project are named \texttt{NeuromorphicFL}. A future algorithm name can be introduced only after the mechanism stabilizes; \emph{LIF-SGD} is currently a descriptive working name rather than a claimed new method name.
