# Independent mock review

This folder contains a versioned mock peer review of the IJCNN 2027 manuscript
at repository commit `ee29e78b9a019b307cd2a4afbc366d5432ded725`.
It is an internal scientific stress test, not an official IJCNN review and not
part of the anonymous submission PDF.

Compile the report from this directory with:

```bash
pdflatex -interaction=nonstopmode -halt-on-error review.tex
pdflatex -interaction=nonstopmode -halt-on-error review.tex
```

The recommendation uses an explicitly stated mock scale because the final
IJCNN 2027 reviewer form and scoring labels were not available when the report
was written.
