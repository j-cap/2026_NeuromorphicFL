\begin{abstract}
Federated learning repeatedly exchanges high-dimensional updates, although
individual coordinates may carry weak but temporally persistent evidence. We
introduce Event-FedAvg, a stateful communication layer inspired by leaky
integrate-and-fire dynamics. Clients accumulate weighted local-model deltas,
emit a signed event when an individual model entry first crosses a threshold
after its previous reset, and reset the corresponding state. Each event changes
the server model by an independently scheduled step magnitude. The server then
sends either the sparse update sequence or, when cheaper, the complete model.
We prove
a pathwise event budget and bounded encoder state, and derive a one-step descent
decomposition with a conditional finite-horizon stationarity result. An exact
pulse-level decomposition and a controlled $2\times2$ audit expose how data
heterogeneity and local-update depth affect finite-trajectory alignment. Under
identical local training conditions across methods, development-only tuning,
and conservative
uplink-plus-downlink accounting, Event-FedAvg is nondominated on held-out
Fashion-MNIST MLP/CNN and CIFAR-10 compact-CNN experiments. On CIFAR-10 it
reaches $48.06\pm1.12\%$ accuracy at $201.5\pm4.3$ Mbit, compared with
$44.13\pm1.12\%$ at $1586.6$ Mbit for development-tuned dense FedAvg. These
results establish a
communication--performance operating point in the evaluated synchronous
setting, not unconditional convergence or hardware-energy savings.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Federated learning (FL) allows a fleet of clients to improve a shared model
without collecting their raw data at one location. Keeping data local,
however, does not make the optimization process communication-free. Every
training round may require high-dimensional client uploads followed by a server
message that brings all clients to the next common model. For bandwidth-limited
edge systems, this repeated exchange can become the main scaling bottleneck of
federated averaging (FedAvg) \cite{mcmahan2017fedavg}.

The difficulty is not only that one update vector is large. A coordinate can be
too weak to justify transmission in a single round while remaining consistent
over several rounds. Round-wise compression does not directly exploit this
temporal persistence. Error-feedback methods preserve discarded residuals for
later correction, but their purpose is to conserve compression error. This
leads to a different design question: \emph{Can each client integrate weak
parameter-wise evidence over time and communicate only when that evidence
crosses a threshold?}

We answer this question with Event-FedAvg, a stateful communication layer for a
conventional model and optimizer. A \emph{coordinate} is one scalar model
parameter. The \emph{client encoder} maps local changes and retained state to
sparse coordinate addresses and signs. Its LIF inspiration is direct: a
leaky integrate-and-fire neuron retains part of its membrane state, adds new
input, fires at a threshold, and resets. Here, each coordinate has such a state
and emits a signed event on crossing. A separate \emph{model quantum} specifies
how far that event moves the server parameter, so evidence threshold and update
magnitude need not coincide.

Sparse uploads alone are not a complete FL protocol because the server update
must return to every client. In \emph{ordered replay}, a client applies the same
sparse packet sequence in the same order as the server. If replay costs more
than the complete float32 model, a \emph{dense-checkpoint fallback} sends that
model instead. Both choices exactly synchronize the next client model.

Our contributions are threefold. We define the complete encoder, server update,
and synchronization algorithm. We prove pathwise state and event-budget
guarantees, derive a conditional finite-horizon optimization result, and
decompose its alignment term into measurable mechanisms. Finally, we compare
Event-FedAvg with dense FedAvg, Sign-EF, EF-TopK, and Strom pulses under
identical local training and total bidirectional traffic. Event-FedAvg is
nondominated in three tested settings. On CIFAR-10, it uses $7.9\times$ less
traffic than dense FedAvg while improving mean accuracy by $3.93$ percentage
points.
Headline comparisons use three held-out seeds and the alignment factorial uses
ten. All runs are synchronous with full participation.

\section{Related Work and Novelty Boundary}
\label{sec:related-work}

One-bit and sign methods reduce precision, while sparse methods with memory and
error feedback preserve compression residuals for later correction
\cite{seide2014onebit,bernstein2018signsgd,stich2018memory,richtarik2021ef21}.
STC applies residual-corrected sparse ternary compression in both FL directions
\cite{sattler2020stc}. Strom's coordinate residuals and signed threshold pulses
are our closest algorithmic predecessor \cite{strom2015distributed}. Unlike its
conservative residual subtraction, Event-FedAvg leaks old evidence, fully
resets fired coordinates, and decouples the trigger threshold from the applied
model quantum.

Event-triggered learning suppresses a vector message until a model or gradient
deviation is large enough \cite{ghadikolaei2021lena,singh2023sparq,he2023etfl,
yoon2025etfl,zhai2026gossip}. Our targeted review did not identify the complete
combination of sampled coordinate crossings, leak, full reset, and an
independent server quantum. This absence search is not proof of priority.
Federated spiking-neural-network (SNN) work instead trains models whose neurons
exchange discrete spikes and maintain LIF states
\cite{venkatesha2021fedsnn,chaki2023tradeoffs,tao2026sfedhifi}. Event-FedAvg
places the LIF-inspired state only in the communication layer around a
conventional model. We claim this complete operator and protocol, not priority
for its individual ingredients.

\section{Event-FedAvg}
\label{sec:method}

This section introduces the quantities in the order in which they appear in one
communication round. We first define local training, then the client event
encoder, and finally the server update and downlink synchronization.

\subsection{Round notation and local update}

Let rounds be indexed by $r\in\{1,\ldots,R\}$, clients by
$i\in\{1,\ldots,M\}$, and model coordinates by $j\in\{1,\ldots,d\}$.
The server model at the start of round $r$ is
$\vect{w}^r\in\mathbb{R}^d$, and every client starts from this same model.
Client $i$ has local objective $F_i$ and aggregation weight $p_i>0$, with
$\sum_i p_i=1$. The server supplies $p_i$ at initialization, commonly as
$n_i/\sum_k n_k$ for $n_i$ local samples. Our equal-size clients use $p_i=1/M$.
The global objective is
\begin{equation}
 F(\vect{w})=\sum_{i=1}^M p_iF_i(\vect{w}).
\end{equation}
Let $\vect{w}_{i,e}^r$ denote client $i$'s local model after local step $e$ in
round $r$. After setting $\vect{w}_{i,0}^r=\vect{w}^r$, the client performs
$E_r$ stochastic-gradient (SGD) steps with learning rate $\eta_r>0$:
\begin{align}
 \vect{w}_{i,e+1}^r&=\vect{w}_{i,e}^r-\eta_r\vect{g}_{i,e}^r,
 \qquad e=0,\ldots,E_r-1, \notag\\
 \vect{\delta}_i^r&=\vect{w}_{i,E_r}^r-\vect{w}^r
 =-\eta_r\sum_{e=0}^{E_r-1}\vect{g}_{i,e}^r .
 \label{eq:local-delta}
\end{align}
Here $\vect{g}_{i,e}^r$ is the stochastic gradient at local model
$\vect{w}_{i,e}^r$. The vector $\vect{\delta}_i^r$ is the complete local model
change supplied to the communication layer.

\subsection{Client event encoder}

Figure~\ref{fig:event-fedavg-method} summarizes the round transition and its two
persistent quantities, namely the post-reset encoder state and the exactly
synchronized server model.

Client $i$ carries a post-reset encoder state
$\vect{z}_i^r\in\mathbb{R}^d$ into round $r$. All experiments initialize
$\vect{z}_i^1=\vect{0}$. The weighted evidence input $\vect{a}_i^r$ and state
immediately before the threshold test, $\widetilde{\vect{z}}_i^r$, are
\begin{equation}
 \vect{a}_i^r=\frac{p_i}{\eta_r}\vect{\delta}_i^r,
 \qquad
 \widetilde{\vect{z}}_i^r=\rho_r\vect{z}_i^r+\vect{a}_i^r,
 \quad 0\leq\rho_r\leq1 .
 \label{eq:evidence-update}
\end{equation}
The factor $p_i$ weights evidence before thresholding and is not applied again
at the server. Division by $\eta_r$ removes the local step size because
$\vect{a}_i^r=-p_i\sum_e\vect{g}_{i,e}^r$, producing comparable
gradient-scale evidence when $\eta_r$ changes. The leak $\rho_r$ retains part
of the preceding state. For threshold $\vartheta>0$, every coordinate is tested
once at round end:
\begin{align}
 m_{ij}^r&=\ind{|\widetilde z_{ij}^r|\geq\vartheta},
 &c_{ij}^r&=m_{ij}^r\operatorname{sign}(\widetilde z_{ij}^r),
 \label{eq:event-pulse}\\
 \vect{z}_i^{r+1}&=(\vect{1}-\vect{m}_i^r)\odot
 \widetilde{\vect{z}}_i^r,
 &\vect{c}_i^r&\in\{-1,0,1\}^d .
 \label{eq:full-reset}
\end{align}
The binary mask $\vect{m}_i^r$ records which coordinates fire, while
$\vect{c}_i^r$ contains the signed pulses sent by the client. A sampled
threshold crossing is the first round after a reset in which
$|\widetilde z_{ij}^r|\geq\vartheta$. Equation~\eqref{eq:full-reset} is a full
reset. A fired coordinate discards its entire pre-trigger state, including
overshoot. It neither subtracts the
threshold nor retains a compression residual. This is the principal semantic
difference from residual-conserving threshold pulses.

\subsection{Server update and synchronization}

The server sums the client pulses into $\vect{C}^r\in\mathbb{Z}^d$. The positive
model quantum $q_r$ is the server-model change caused by one net signed event.
It is common to all coordinates in a round but independent of $\vartheta$:
\begin{equation}
 \vect{C}^r=\sum_{i=1}^M\vect{c}_i^r,
 \qquad
 \vect{w}^{r+1}=\vect{w}^r+q_r\vect{C}^r .
 \label{eq:server-update}
\end{equation}
The experiments prescribe $q_r=q_0(1+r/r_0)^{-\alpha}$, where $q_0>0$ is the
initial quantum, $r_0>0$ is a round scale, and $\alpha\geq0$ is the decay
exponent. Clients recover $q_r$
from the round index and transmit no floating-point event magnitude. If several
clients fire on the same coordinate in the same round, these \emph{coincident
pulses} reinforce when their signs agree and cancel when they disagree. For
example, $C_j^r=2$ moves parameter $w_j$ by $2q_r$. There is no normalization by
messages or events.

A nonempty client packet carries a 64-bit header for metadata such as sender,
round, type, and length. Each event adds one sign bit and a
$\lceil\log_2d\rceil$-bit address, the fixed-length code needed for $d$ possible
indices. The header is an accounting convention, not part of the mathematical
operator. The server returns the ordered packet stream or, when smaller, a
dense float32 copy of $\vect{w}^{r+1}$. The conservative total counts initial
synchronization, a 32-bit catch-up request, and one downlink copy per client and
round. These choices affect traffic, not the update in
\eqref{eq:server-update}. Algorithm~\ref{alg:event-fedavg} states the complete
ordering used in all final experiments.

\noindent\rule{\columnwidth}{0.8pt}
\begin{algorithm}[Event-FedAvg communication layer]
\label{alg:event-fedavg}
\normalfont\small
Initialize $\vect{w}^1$ and $\vect{z}_i^1=\vect{0}$. The server supplies
$p_i$, $\vartheta$, and the schedules $\eta_r$, $\rho_r$, and $q_r$. For each
round $r=1,\ldots,R$:
\begin{enumerate}
  \item \textbf{Local learning:} Every client starts from $\vect{w}^r$,
  performs $E_r$ local SGD steps, and forms $\vect{\delta}_i^r$
  using~\eqref{eq:local-delta}.
  \item Client $i$ computes
  $\widetilde{\vect{z}}_i^r=\rho_r\vect{z}_i^r+
  (p_i/\eta_r)\vect{\delta}_i^r$ and forms $\vect{m}_i^r$ and
  $\vect{c}_i^r$ using~\eqref{eq:event-pulse}.
  \item Client $i$ resets the fired states using~\eqref{eq:full-reset} and
  sends the indices and signs of the nonzero entries of $\vect{c}_i^r$.
  \item \textbf{Server update:} The server forms
  $\vect{C}^r=\sum_i\vect{c}_i^r$ and sets
  $\vect{w}^{r+1}=\vect{w}^r+q_r\vect{C}^r$.
  \item \textbf{Synchronization:} The server returns the ordered sparse packet
  stream or, when smaller, a dense checkpoint. Every client then holds
  $\vect{w}^{r+1}$.
\end{enumerate}
\end{algorithm}

\section{Scoped Theoretical Characterization}
\label{sec:theory}

We separate encoder properties that hold for every realized input sequence
from the assumption needed to connect emitted events to optimization.

\begin{proposition}[State and pathwise event budget]
Assume $|z_{ij}^1|<\vartheta$ initially. The full-reset encoder keeps
$|z_{ij}^r|<\vartheta$ in every round. If
$N_R^{\rm coord}=\sum_{r=1}^R\sum_{i,j}m_{ij}^r$, then
\begin{equation}
 N_R^{\rm coord}\leq\frac{1}{\vartheta}
 \left(\sum_i\norm{\vect{z}_i^1}_1+
 \sum_{r=1}^R\sum_i\norm{\vect{a}_i^r}_1\right).
 \label{eq:event-budget}
\end{equation}
Consequently, if $P_R$ is the number of nonempty packets, the exact event
uplink is $64P_R+(\lceil\log_2d\rceil+1)N_R^{\rm coord}$ bits.
\end{proposition}
The state claim follows immediately from the threshold test and full reset.
For~\eqref{eq:event-budget}, expand the leaky recurrence over each disjoint
reset-to-event block. Every leak product is at most one, while threshold
crossing requires at least $\vartheta$ total absolute evidence in that block.
This bound is deterministic and permits biased, dependent, or nonstationary
inputs. It is an upper bound, not a guarantee that weak evidence fires.

Write $\vect{g}^r=\nabla F(\vect{w}^r)$ and let
$N_r=\sum_i\norm{\vect{c}_i^r}_0$ denote the number of client-coordinate events in
round $r$. To distinguish pulses that agree with a descent direction from those
that oppose it, define
\begin{align}
 D_r&=\sum_{i,j:\,c_{ij}^rg_j^r<0}|g_j^r|,
 &H_r&=\sum_{i,j:\,c_{ij}^rg_j^r>0}|g_j^r| .
\end{align}
The realized aggregate alignment is then
\begin{equation}
 A_r=-\langle\vect{g}^r,\vect{C}^r\rangle=D_r-H_r,
 \label{eq:alignment}
\end{equation}
where $D_r$ and $H_r$ are respectively the global-gradient mass carried by
client pulses opposing and following $\vect{g}^r$. This definition already
accounts for reinforcement and cancellation on a shared coordinate. It also
defines the same $A_r$ used below in~\eqref{eq:alignment-decomposition}. For
each coordinate, Cauchy--Schwarz gives
$(\sum_i c_{ij}^r)^2\leq M\sum_i(c_{ij}^r)^2$. Because
$(c_{ij}^r)^2=m_{ij}^r$, summing over $j$ yields
$\norm{\vect{C}^r}_2^2\leq MN_r$. This bounds the squared server-update norm
using only the number of transmitted events.

To expose the mechanisms hidden inside $A_r$, let
$\mathcal S_i^r=\{j:c_{ij}^r\neq0\}$, write $s_{ij}^r=c_{ij}^r$ on this set,
and define the current local gradient
$\vect{g}_i^r=\nabla F_i(\vect{w}^r)$ and local-update proxy
$\vect{v}_i^r=\vect{\delta}_i^r/(\eta_rE_r)$. For emitted client-coordinate
pairs, set
\begin{align}
 P_r&=\sum_{i,j\in\mathcal S_i^r}|v_{ij}^r|,
 &R_r&=2\sum_{i,j\in\mathcal S_i^r}|v_{ij}^r|
 \ind{s_{ij}^rv_{ij}^r<0}, \notag\\
 L_r&=\sum_{i,j\in\mathcal S_i^r}(-g_{ij}^r-v_{ij}^r)s_{ij}^r,
 &B_r&=\sum_{i,j\in\mathcal S_i^r}(g_{ij}^r-g_j^r)s_{ij}^r.
 \label{eq:alignment-components}
\end{align}
$P_r$ is the alignment with the current local-update proxy, $R_r$ is the
penalty from accumulated state firing against that proxy, $L_r$ contains local
drift and stochastic-gradient mismatch, and $B_r$ contains client-to-global
heterogeneity.

\begin{proposition}[Exact alignment decomposition]
For every realized round,
\begin{equation}
 A_r=P_r-R_r+L_r+B_r.
 \label{eq:alignment-decomposition}
\end{equation}
\end{proposition}
For each emitted pair, add and subtract $v_{ij}^r$ and $g_{ij}^r$ in
$-g_j^rs_{ij}^r$, then use $v_{ij}^rs_{ij}^r=
|v_{ij}^r|-2|v_{ij}^r|\ind{s_{ij}^rv_{ij}^r<0}$. Summing gives
\eqref{eq:alignment-decomposition}. Its terms respectively describe current
local-update agreement, memory opposition, local mismatch, and heterogeneity.
Because $L_r$ and $B_r$ have unrestricted signs, the identity does not prove
positive alignment.

\begin{proposition}[Descent and conditional stationarity]
If $F$ is $L$-smooth, every realized round obeys
\begin{equation}
 F(\vect{w}^{r+1})\leq F(\vect{w}^r)-q_rA_r+\frac{LM}{2}q_r^2N_r.
 \label{eq:descent}
\end{equation}
Let $\mathcal{F}_r$ contain all randomness revealed before round-$r$ local
computation, and suppose, for $\kappa>0$ and deterministic $\beta_r\geq0$,
\begin{equation}
 \E[A_r\mid\mathcal{F}_r]\geq
 \kappa\norm{\nabla F(\vect{w}^r)}_2^2-\beta_r .
 \label{eq:alignment-assumption-paper}
\end{equation}
If the objective has finite lower bound $F_{\inf}$, meaning
$F(\vect{w})\geq F_{\inf}$ for every $\vect{w}$, and $\vect{w}^1$ is
deterministic, define
$Q_R=\sum_{r=1}^Rq_r$ and independently draw $J_R$ with
$\Pr(J_R=r)=q_r/Q_R$. Then
\begin{align}
 \kappa Q_R\E\norm{\nabla F(\vect{w}^{J_R})}_2^2
 &\leq F(\vect{w}^1)-F_{\inf}+\sum_rq_r\beta_r \notag\\
 &\quad+\frac{LM}{2}\sum_rq_r^2\E N_r .
 \label{eq:stationarity}
\end{align}
\end{proposition}
Equation~\eqref{eq:descent} applies $L$-smoothness to $q_r\vect{C}^r$, uses
$A_r$ for the first-order term, and bounds the quadratic term by
$\norm{\vect{C}^r}_2^2\leq MN_r$. For~\eqref{eq:stationarity}, take conditional
expectations, insert~\eqref{eq:alignment-assumption-paper}, sum, telescope the
objectives, and apply $F\geq F_{\inf}$. The choice of $J_R$ gives
$\E\norm{\nabla F(\vect{w}^{J_R})}_2^2=Q_R^{-1}\sum_rq_r
\E\norm{\nabla F(\vect{w}^r)}_2^2$. It reports one weighted-random iterate
without assuming that the final iterate is best.

The result is deliberately conditional. Silence, leakage, stale evidence,
local drift, sign errors, and heterogeneity may all require a larger $\beta_r$.
The empirical quantum-schedule exponents $0.1$, $0.2$, and $0.3$ are used only
over the reported finite horizons. We therefore make no asymptotic convergence
claim.

At selected rounds, we replay the recorded state and compute full client and
global gradients at $\vect{w}^r$ after the event decision. These gradients
evaluate $A_r$ and~\eqref{eq:alignment-decomposition}, but cannot alter training
or later crossings. For audited rounds $\mathcal A$, define
\begin{equation}
 \widehat\kappa_{\mathcal A}=
 \frac{\sum_{r\in\mathcal A}q_rA_r}
 {\sum_{r\in\mathcal A}q_r\norm{\nabla F(\vect{w}^r)}_2^2}.
 \label{eq:empirical-alignment-ratio}
\end{equation}
This dimensionless ratio compares realized first-order descent with
global-gradient energy. A positive value means average $q_r$-weighted descent
alignment. It is neither mean $A_r$ nor the theoretical $\kappa$, except as an
empirical analogue when $\beta_r=0$, and it does not prove the conditional
expectation. Section~\ref{sec:results} combines it with the decomposition to
explain observed heterogeneity and local-depth effects.

\section{Experimental Protocol}
\label{sec:experiments}

\textbf{Tasks and models.}
We evaluate ten-client image classification under strong label skew. The
Fashion-MNIST campaign uses a 25,818-parameter MLP for 150 rounds and a
14,538-parameter compact CNN for 80 rounds. CIFAR-10 uses a conventional
20,570-parameter CNN for 120 rounds. It has two strided convolutional layers with
8 and 16 channels, a 32-unit hidden layer, and a ten-class output. No model is
spiking. Each CIFAR-10 client holds 5,000 examples: 2,750 from its dominant
class and 250 from every other class. All headline runs use ten active clients,
five local SGD steps, and minibatches of 32. The local learning rate is $0.1$ on
Fashion-MNIST and $0.05$ on CIFAR-10. The Event-FedAvg settings
use $r_0=100$ and quantum exponents $\alpha=0.1$, $0.3$, and $0.2$ for the
Fashion-MNIST MLP, Fashion-MNIST CNN, and CIFAR-10 CNN, respectively, in the
schedule after~\eqref{eq:server-update}.

\textbf{Selection and evaluation.}
We compare Event-FedAvg with dense FedAvg~\cite{mcmahan2017fedavg}, Sign-EF
based on sign quantization and error feedback
\cite{seide2014onebit,bernstein2018signsgd}, EF-TopK with memory
\cite{stich2018memory,richtarik2021ef21}, and Strom's residual-conserving
threshold pulses~\cite{strom2015distributed}. \emph{Matched local learning}
means identical client data, initialization, local steps, learning rate, and
minibatch order for every method sharing a seed. Only communication and its
server update differ.

Hyperparameters are selected on one development partition per dataset. The
best-quality setting minimizes development training loss. For dense FedAvg,
the server gain $\gamma$ scales the usual aggregate as
$\vect{w}^{r+1}=\vect{w}^r+\gamma\sum_i p_i\vect{\delta}_i^r$. On CIFAR-10,
$\gamma=2$ is selected from $\{0.25,0.5,0.75,1,1.5,2,4\}$. For Strom and
EF-TopK, we also freeze the development setting closest to Event-FedAvg in log
total traffic. Final values are mean and sample standard deviation over three
held-out strong-skew partitions with paired training seeds across methods.
Test cross-entropy (CE), accuracy, worst-class accuracy, coordinate events, and
communication are recorded. No held-out result influences selection.

\textbf{Communication metric.}
The primary metric, \emph{conservative bidirectional unicast traffic}, counts
uploads plus a separate downlink copy for every client, without a broadcast
discount. It includes headers, addresses, signs or values, initial
synchronization, a 32-bit per-round request, and the smaller of replay and a
float32 checkpoint. Applying one rule to every method prevents an omitted
downlink from making sparse communication appear artificially cheap.

\textbf{Alignment factorial.}
On the Fashion-MNIST MLP, we run a full $2\times2$ factorial: every paired seed
is evaluated with either IID or strong non-IID client data and with either one
or five local steps, while all other Event-FedAvg settings remain fixed.
For each of ten paired partition and training seeds, rounds
$1,5,10,\ldots,150$ are
independently replayed. Exact gradients use all 6,000 examples of every client
and are evaluated only after the audited event decision, preventing the
diagnostic computation from perturbing later threshold crossings.

On Fashion-MNIST MLP, Event-FedAvg attains
$83.14\pm0.14\%$ at $183.5\pm2.0$ Mbit. The strongest quality-selected
baseline, EF-TopK, reaches $82.45\pm0.19\%$ using $1010.5$ Mbit, whereas the
nearest-traffic Strom point reaches $79.51\pm0.86\%$ at
$181.0\pm6.7$ Mbit. The CNN exposes the important qualification. Strom gains
$0.90$ accuracy points, but requires $359.5\pm4.3$ Mbit versus
$72.8\pm1.2$ Mbit. At nearby traffic, Event-FedAvg exceeds Strom by
$1.46$ points.

The separately developed CIFAR-10 experiment tests transfer beyond
Fashion-MNIST.
Event-FedAvg obtains the best mean accuracy and cross-entropy among the
quality-selected methods while using the least traffic. Compared with dense
FedAvg tuned to server gain $2$, its $48.06\pm1.12\%$ accuracy is
$3.93$ points higher at only $12.7\%$ of the traffic. Tuned dense FedAvg
reaches $44.13\pm1.12\%$. Quality-selected Strom reaches
$47.68\pm0.49\%$ but uses
$4.6\times$ more traffic. Its nearest-traffic variant uses $10.1\%$ more
traffic and trails by $12.56$ points. The nearest EF-TopK point is a genuine
trade-off. It uses $32.9\%$ less traffic but trails by $7.10$ points.

The targeted mechanism audit narrows the LIF interpretation. A like-for-like
rerun of the frozen Event-FedAvg setting gives $48.25\pm1.07\%$ at
$200.2\pm2.2$ Mbit. Removing leakage ($\rho=1$) gives
$48.32\pm1.05\%$ at $202.1\pm5.6$ Mbit. Thus leakage at $\rho=0.999$ has no
material isolated effect at this resolution. In contrast, coupling the server
quantum to the trigger as $q_r=\vartheta=0.025$ reduces accuracy to
$18.42\pm7.33\%$ at $44.8\pm17.7$ Mbit. This supports independent trigger and
update resolutions for the selected operating point, not a universal claim
that every coupled schedule fails.

Table~\ref{tab:alignment-factorial} reports the Fashion-MNIST MLP factorial.
Each row summarizes ten seeds with 31 replayed rounds each. The displayed
$\widehat\kappa_{\mathcal A}$ is the trajectory ratio in
\eqref{eq:empirical-alignment-ratio}, not mean $A_r$ and not the theoretical
$\kappa$ in~\eqref{eq:alignment-assumption-paper}. The next three columns show
how often the event direction is first-order aligned, how often the objective
actually decreases, and how often positive alignment nevertheless fails to
produce descent.

$\overline B_{\mathcal A}$ exposes the adverse heterogeneity contribution.
$\overline L_{\mathcal A}$ shows that local depth acts differently under IID
and non-IID data, so the terms interact rather than form independent penalties.
The final column is the remainder after the first-order change. With strong
non-IID data, deeper training keeps frequent positive alignment but yields
fewer objective decreases and a larger remainder. No emitted pulse opposes the
current local-update proxy in the $1{,}240$ snapshots, so $R_r=0$. This explains
a finite-step heterogeneity--depth limitation without establishing the
conditional expectation in~\eqref{eq:alignment-assumption-paper}.

The frontier is not uniform predictive dominance. On CIFAR-10,
quality-selected EF-TopK obtains slightly higher mean worst-class accuracy
($26.7\%$) than Event-FedAvg ($24.6\%$). Tuned dense FedAvg reaches $23.3\%$.
All estimates use
only three held-out seeds. Together with the alignment audit in
Section~\ref{sec:theory}, the results support the proposed finite-horizon
communication mechanism, but do not establish the conditional assumption or
statistical significance.

\section{Limitations}
\label{sec:limitations}

The experiments cover synchronous full participation, ten clients, and two
image datasets. The communication--performance comparisons use three held-out
seeds per setting, while the factorial audit uses ten seeds but varies only two
factors around one Fashion-MNIST operating point and is not a broad robustness
study. The results do not establish
statistical significance or broad dataset and model generalization. The theory
does not prove the aggregate-alignment condition for the coupled learning
process, and the evaluated quantum schedules do not support an asymptotic
convergence claim. Communication is counted in software-level bits under an
exact synchronization protocol. We do not measure latency, packet loss,
asynchronous execution, or neuromorphic-hardware energy.

\section{Conclusion}
\label{sec:conclusion}

Event-FedAvg turns temporally accumulated local-update evidence into sparse
signed events using leakage, full reset, and a trigger-independent model
quantum. The complete protocol includes the downlink required for exact client
synchronization. Pathwise guarantees cover encoder state and event count, while
alignment remains the explicit optimization condition. Event-FedAvg is
nondominated in the evaluated synchronous ten-client settings. The audit shows
that quantum decoupling matters for the selected configuration, leakage at
$\rho=0.999$ has no measurable isolated effect, and heterogeneity can turn
positive first-order alignment into non-descent. These findings sharpen both
the contribution and its boundary. Next tests should target more paired seeds,
partial participation, and measured communication systems.
