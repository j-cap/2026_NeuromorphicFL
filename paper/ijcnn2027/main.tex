\begin{abstract}
Federated learning repeatedly exchanges high-dimensional updates, although
individual coordinates may carry weak but temporally persistent evidence. We
introduce Event-FedAvg, a stateful communication layer inspired by leaky
integrate-and-fire dynamics. Clients accumulate weighted local-model deltas,
emit a signed event when an individual model entry first crosses a threshold
after its previous reset, and reset the corresponding state. \rev{The server
sums simultaneous signed events coordinatewise. Agreeing events reinforce,
opposing events cancel, and the resulting net event count moves the model by an
independently scheduled quantum.} The server then
sends either the sparse update sequence or, when cheaper, the complete model.
\rev{Our pathwise analysis guarantees a bounded encoder state and relates the
number of transmitted events directly to accumulated client evidence, without
requiring independent or identically distributed updates. We also derive a
one-step descent decomposition with a conditional finite-horizon gradient-norm
bound.} An exact pulse-level decomposition and a \rev{factorial alignment audit}
expose how data
heterogeneity and local-update depth affect finite-trajectory alignment. Under
identical local training conditions across methods, development-only tuning,
and conservative
uplink-plus-downlink accounting, Event-FedAvg is nondominated on held-out
Fashion-MNIST MLP/CNN and CIFAR-10 compact-CNN and ResNet-14 experiments.
\rev{Across ten paired ResNet-14 seeds, it reaches $75.14\pm0.46\%$ accuracy
at $21.04\pm0.19$ Gbit, compared with $69.47\pm0.62\%$ at $201.96$ Gbit for
development-tuned dense FedAvg.} These
results establish a
communication--performance operating point in the evaluated synchronous
setting, not unconditional convergence or hardware-energy savings.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Federated learning (FL) allows a fleet of clients to improve a shared model
without collecting their raw data at one location. Keeping data local,
however, does not make the optimization process communication-free. Every
training round may require high-dimensional client uploads followed by a server
message that brings all clients to the next common model. For bandwidth-limited
edge systems, this repeated exchange can become the main scaling bottleneck of
federated averaging (FedAvg) \cite{mcmahan2017fedavg}.

\rev{A \emph{coordinate} is one scalar entry of the model vector. Its change
may be too small to justify transmission in one round, even when changes in the
same direction persist and accumulate into meaningful evidence over several
rounds.} Round-wise compression does not directly exploit this temporal
persistence. Error-feedback methods preserve discarded residuals for
later correction \rev{\cite{stich2018memory,richtarik2021ef21}}, but their
purpose is to conserve compression error. This
leads to a different design question: \emph{Can each client integrate weak
parameter-wise evidence over time and communicate only when that evidence
crosses a threshold?}

We answer this question with Event-FedAvg, a stateful communication layer for a
conventional model and optimizer. The \emph{client encoder} maps local changes
and retained state to sparse coordinate addresses and signs. \rev{The design is
inspired by a leaky integrate-and-fire (LIF) neuron~\cite{gerstner2014neuronal},
which retains part of its
membrane state, adds new
input, fires at a threshold, and resets. Here, each coordinate has such a state
and emits a signed event on crossing. A separate \emph{model quantum} specifies
how far that event moves the server parameter, so evidence threshold and update
magnitude need not coincide.}

After every server update--including a no-event round--the server must
synchronize all clients before the next round. It returns either \emph{ordered
replay}, the sparse packet sequence in server order, or, when cheaper, a
\emph{dense-checkpoint fallback} containing the complete float32 model. Both
choices exactly synchronize the next client model.

Our contributions are threefold. We define the complete encoder, server update,
and synchronization algorithm. We prove pathwise state and event-budget
guarantees, derive a conditional finite-horizon gradient-norm bound, and
decompose its alignment term into measurable mechanisms. Finally, we compare
Event-FedAvg with \rev{dense FedAvg~\cite{mcmahan2017fedavg}, Sign-EF based on
sign quantization and error feedback~\cite{seide2014onebit,bernstein2018signsgd},
EF-TopK with memory~\cite{stich2018memory,richtarik2021ef21}, and Strom
pulses~\cite{strom2015distributed}} under
identical local training and total bidirectional traffic. Event-FedAvg is
nondominated in \rev{all four} tested settings. \rev{On CIFAR-10 ResNet-14, it
uses $9.6\times$ less traffic than dense FedAvg while improving mean accuracy
by $5.66$ percentage points.}
Headline comparisons and the alignment factorial each use ten paired seeds.
All runs are synchronous with full participation.
\rev{Figure~\ref{fig:event-fedavg-method} previews one complete communication
round, including the client-side state, server aggregation, and mandatory
downlink synchronization.}

\section{\rev{Related Work}}
\label{sec:related-work}

One-bit and sign methods reduce precision, while sparse methods with memory and
error feedback preserve compression residuals for later correction
\cite{seide2014onebit,bernstein2018signsgd,stich2018memory,richtarik2021ef21}.
\rev{Sparse Ternary Compression (STC) applies residual-corrected ternary
sparsification in both FL directions}
\cite{sattler2020stc}. Strom's coordinate residuals and signed threshold pulses
are our closest algorithmic predecessor \cite{strom2015distributed}. Unlike its
conservative residual subtraction, Event-FedAvg leaks old evidence, fully
resets fired coordinates, and decouples the trigger threshold from the applied
model quantum.

Event-triggered learning suppresses a vector message until a model or gradient
deviation is large enough \cite{ghadikolaei2021lena,singh2023sparq,he2023etfl,
yoon2025etfl,zhai2026gossip}. \rev{Relative to these approaches, Event-FedAvg
combines sampled coordinate crossings, leakage, full reset, and an independent
server quantum in one exactly synchronized communication protocol.}
Federated spiking-neural-network (SNN) work instead trains models whose neurons
exchange discrete spikes and maintain LIF states
\cite{venkatesha2021fedsnn,chaki2023tradeoffs,tao2026sfedhifi}. Event-FedAvg
places the LIF-inspired state only in the communication layer around a
conventional model. \rev{The contribution is therefore the combined
communication operator and its analysis, rather than any individual
ingredient in isolation.}

\section{Event-FedAvg}
\label{sec:method}

This section introduces the quantities in the order in which they appear in one
communication round. We first define local training, then the client event
encoder, and finally the server update and downlink synchronization.

\subsection{Round notation and local update}

Let rounds be indexed by $r\in\{1,\ldots,R\}$, clients by
$i\in\{1,\ldots,M\}$, and model coordinates by $j\in\{1,\ldots,d\}$.
The server model at the start of round $r$ is
$\vect{w}^r\in\mathbb{R}^d$, and every client starts from this same model.
Client $i$ has local objective $F_i$ and aggregation weight $p_i>0$, with
$\sum_i p_i=1$. The server supplies $p_i$ at initialization, commonly as
$n_i/\sum_k n_k$ for $n_i$ local samples. Our equal-size clients use $p_i=1/M$.
The global objective is
\begin{equation}
 F(\vect{w})=\sum_{i=1}^M p_iF_i(\vect{w}).
\end{equation}
Let $\vect{w}_{i,e}^r$ denote client $i$'s local model after local step $e$ in
round $r$. After setting $\vect{w}_{i,0}^r=\vect{w}^r$, the client performs
$E_r$ stochastic-gradient (SGD) steps with learning rate $\eta_r>0$:
\begin{align}
 \vect{w}_{i,e+1}^r&=\vect{w}_{i,e}^r-\eta_r\vect{g}_{i,e}^r,
 \qquad e=0,\ldots,E_r-1, \notag\\
 \vect{\delta}_i^r&=\vect{w}_{i,E_r}^r-\vect{w}^r
 =-\eta_r\sum_{e=0}^{E_r-1}\vect{g}_{i,e}^r .
 \label{eq:local-delta}
\end{align}
Here $\vect{g}_{i,e}^r$ is the stochastic gradient at local model
$\vect{w}_{i,e}^r$. The vector $\vect{\delta}_i^r$ is the complete local model
change supplied to the communication layer.

\subsection{Client event encoder}

\rev{Each client maintains one encoder-state entry per model coordinate.
At the start of round $r$, client $i$ carries the post-reset state
$\vect{z}_i^r\in\mathbb{R}^d$ forward from the preceding round. All experiments
initialize this state as $\vect{z}_i^1=\vect{0}$. The client converts its local
model change into weighted evidence and combines that evidence with the retained
state before testing the threshold. Figure~\ref{fig:event-fedavg-method}
summarizes this transition. It also shows the two quantities carried into the
next round. Client $i$ retains $\vect{z}_i^{r+1}$, and every client receives the
exactly synchronized server model $\vect{w}^{r+1}$.}

The weighted evidence input $\vect{a}_i^r$ and state
immediately before the threshold test, $\widetilde{\vect{z}}_i^r$, are
\begin{equation}
 \vect{a}_i^r=\frac{p_i}{\eta_r}\vect{\delta}_i^r,
 \qquad
 \widetilde{\vect{z}}_i^r=\rho_r\vect{z}_i^r+\vect{a}_i^r,
 \quad 0\leq\rho_r\leq1 .
 \label{eq:evidence-update}
\end{equation}
The factor $p_i$ weights evidence before thresholding and is not applied again
at the server. Division by $\eta_r$ removes the local step size because
$\vect{a}_i^r=-p_i\sum_e\vect{g}_{i,e}^r$, producing comparable
gradient-scale evidence when $\eta_r$ changes. The leak $\rho_r$ retains part
of the preceding state. For threshold $\vartheta>0$, every coordinate is tested
once at round end:
\begin{align}
 m_{ij}^r&=\ind{|\widetilde z_{ij}^r|\geq\vartheta},
 &c_{ij}^r&=m_{ij}^r\operatorname{sign}(\widetilde z_{ij}^r),
 \label{eq:event-pulse}\\
 \vect{z}_i^{r+1}&=(\vect{1}-\vect{m}_i^r)\odot
 \widetilde{\vect{z}}_i^r,
 &\vect{c}_i^r&\in\{-1,0,1\}^d .
 \label{eq:full-reset}
\end{align}
The binary mask $\vect{m}_i^r$ records which coordinates fire, while
$\vect{c}_i^r$ contains the signed pulses sent by the client. A sampled
threshold crossing is the first round after a reset in which
$|\widetilde z_{ij}^r|\geq\vartheta$. Equation~\eqref{eq:full-reset} is a full
reset. A fired coordinate discards its entire pre-trigger state, including
overshoot. It neither subtracts the
threshold nor retains a compression residual. This is the principal semantic
difference from residual-conserving threshold pulses
\rev{\cite{stich2018memory,strom2015distributed}}.

\subsection{Server update and synchronization}

The server sums the client pulses into $\vect{C}^r\in\mathbb{Z}^d$. The positive
model quantum $q_r$ is the server-model change caused by one net signed event.
It is common to all coordinates in a round but independent of $\vartheta$:
\begin{equation}
 \vect{C}^r=\sum_{i=1}^M\vect{c}_i^r,
 \qquad
 \vect{w}^{r+1}=\vect{w}^r+q_r\vect{C}^r .
 \label{eq:server-update}
\end{equation}
The experiments prescribe $q_r=q_0(1+r/r_0)^{-\alpha}$, where $q_0>0$ is the
initial quantum, $r_0>0$ is a round scale, and $\alpha\geq0$ is the decay
exponent. Clients recover $q_r$
from the round index and transmit no floating-point event magnitude. If several
clients fire on the same coordinate in the same round, these \emph{coincident
pulses} reinforce when their signs agree and cancel when they disagree. For
example, $C_j^r=2$ moves parameter $w_j$ by $2q_r$. There is no normalization by
messages or events.

A nonempty client packet carries a 64-bit header for metadata such as sender,
round, type, and length. Each event adds one sign bit and a
$\lceil\log_2d\rceil$-bit address, the fixed-length code needed for $d$ possible
indices. The header is an accounting convention, not part of the mathematical
operator. The server returns the ordered packet stream or, when smaller, a
\rev{dense checkpoint containing $\vect{w}^{r+1}$. In the conservative traffic
metric, every client is charged for the initial model synchronization and for
one complete synchronization response after each round. A small request packet
is also counted when a client asks for the response.} These choices affect
traffic, not the update in
\eqref{eq:server-update}. Algorithm~\ref{alg:event-fedavg} states the complete
ordering used in all final experiments.

\begin{samepage}
\noindent\rule{\columnwidth}{0.8pt}
\begin{algorithm}[Event-FedAvg communication layer]
\label{alg:event-fedavg}
\normalfont\small
Initialize $\vect{w}^1$ and $\vect{z}_i^1=\vect{0}$. The server supplies
$p_i$, $\vartheta$, and the schedules $\eta_r$, $\rho_r$, and $q_r$. For each
round $r=1,\ldots,R$:
\begin{enumerate}
  \item \textbf{Local learning:} Every client starts from $\vect{w}^r$,
  performs $E_r$ local SGD steps, and forms $\vect{\delta}_i^r$
  using~\eqref{eq:local-delta}.
  \item Client $i$ computes
  $\widetilde{\vect{z}}_i^r=\rho_r\vect{z}_i^r+
  (p_i/\eta_r)\vect{\delta}_i^r$ and forms $\vect{m}_i^r$ and
  $\vect{c}_i^r$ using~\eqref{eq:event-pulse}.
  \item Client $i$ resets the fired states using~\eqref{eq:full-reset} and
  sends the indices and signs of the nonzero entries of $\vect{c}_i^r$.
  \item \textbf{Server update:} The server forms
  $\vect{C}^r=\sum_i\vect{c}_i^r$ and sets
  $\vect{w}^{r+1}=\vect{w}^r+q_r\vect{C}^r$.
  \item \textbf{Synchronization after every round:} Including when no event
  fires, the server returns the ordered sparse stream or a smaller dense
  checkpoint. Every client then holds $\vect{w}^{r+1}$.
\end{enumerate}
\end{algorithm}

\section{\rev{Finite-Horizon Communication and Alignment Analysis}}
\label{sec:theory}

\rev{This section answers three questions in sequence: how many coordinate
events the encoder can emit along a realized optimization trajectory, how those events
align with the current global descent direction, and what additional alignment
condition is sufficient for a finite-horizon optimization bound.}

\rev{For the first $R$ rounds, let $N_R^{\rm coord}$ denote the total number of
client-coordinate events. Every fired coordinate of every client contributes
one count, even when another client's opposite event later cancels it at the
server:}
\begin{equation}
 \rev{N_R^{\rm coord}=\sum_{r=1}^R\sum_{i=1}^M\sum_{j=1}^d m_{ij}^r.}
 \label{eq:coordinate-event-count}
\end{equation}

\begin{proposition}[State and pathwise event budget]
Assume $|z_{ij}^1|<\vartheta$ initially. The full-reset encoder keeps
$|z_{ij}^r|<\vartheta$ in every round. \rev{The total in
\eqref{eq:coordinate-event-count} satisfies}
\begin{equation}
 N_R^{\rm coord}\leq\frac{1}{\vartheta}
 \left(\sum_i\norm{\vect{z}_i^1}_1+
 \sum_{r=1}^R\sum_i\norm{\vect{a}_i^r}_1\right).
 \label{eq:event-budget}
\end{equation}
Consequently, if $P_R$ is the number of nonempty packets, the exact event
uplink is $64P_R+(\lceil\log_2d\rceil+1)N_R^{\rm coord}$ bits.
\end{proposition}
The threshold test and reset prove the state claim. Partition each coordinate
trajectory into disjoint reset-to-event blocks. On a block $s{:}t$, the
recurrence and $0\leq\rho_r\leq1$ give
$|\widetilde z_{ij}^{t}|\leq|z_{ij}^{s}|+\sum_{\tau=s}^{t}|a_{ij}^{\tau}|$.
At an event the left side is at least $\vartheta$. Summing the blocks, of which
only the first uses the initial state, proves~\eqref{eq:event-budget}. The bound
\rev{is pathwise: it holds for each realized sequence of local updates, without
averaging over training randomness or assuming independence. It therefore
gives a deterministic accounting link between accumulated evidence and event
traffic. The result does not imply that weak evidence must eventually fire.}

\rev{Let $\vect{g}^r=\nabla F(\vect{w}^r)$ be the global gradient at the current
server model,} and let
$N_r=\sum_i\norm{\vect{c}_i^r}_0$ denote the number of client-coordinate events in
round $r$. To distinguish pulses that agree with a descent direction from those
that oppose it, define
\begin{align}
 D_r&=\sum_{i,j:\,c_{ij}^rg_j^r<0}|g_j^r|,
 &H_r&=\sum_{i,j:\,c_{ij}^rg_j^r>0}|g_j^r| .
\end{align}
The realized aggregate alignment is then
\begin{equation}
 A_r=-\langle\vect{g}^r,\vect{C}^r\rangle=D_r-H_r,
 \label{eq:alignment}
\end{equation}
Here $D_r$ and $H_r$ are helpful and harmful global-gradient mass.
\rev{For an emitted pulse, $c_{ij}^rg_j^r<0$ means that the pulse points
opposite the gradient and hence toward first-order descent, whereas
$c_{ij}^rg_j^r>0$ means that it points with the gradient and is harmful to
first order.}
\rev{Aggregation includes same-coordinate reinforcement and cancellation. This
is the same $A_r$ as in~\eqref{eq:alignment-decomposition}.} Coordinatewise,
\rev{the aggregate entry is $C_j^r=\sum_i c_{ij}^r$. Applying
Cauchy--Schwarz to the vectors $(1,\ldots,1)$ and
$(c_{1j}^r,\ldots,c_{Mj}^r)$ gives}
$(\sum_i c_{ij}^r)^2\leq M\sum_i(c_{ij}^r)^2$. Because
$(c_{ij}^r)^2=m_{ij}^r$, summing over $j$ yields
$\norm{\vect{C}^r}_2^2\leq MN_r$. \rev{Thus cancellation can make the actual
aggregate smaller, while $MN_r$ remains a worst-case bound determined only by
the transmitted event count.}

\rev{The scalar $A_r$ says whether the aggregate update is helpful, but not why.
To separate the effects of current local updates, retained encoder memory,
local optimization, and client heterogeneity, let}
$\mathcal S_i^r=\{j:c_{ij}^r\neq0\}$, write $s_{ij}^r=c_{ij}^r$ on this set,
and define the local gradient
$\vect{g}_i^r=\nabla F_i(\vect{w}^r)$ and update proxy
$\vect{v}_i^r=\vect{\delta}_i^r/(\eta_rE_r)$. For emitted client-coordinate
pairs, set
\begin{align}
 P_r&=\sum_{i,j\in\mathcal S_i^r}|v_{ij}^r|,
 &R_r&=2\sum_{i,j\in\mathcal S_i^r}|v_{ij}^r|
 \ind{s_{ij}^rv_{ij}^r<0}, \notag\\
 L_r&=\sum_{i,j\in\mathcal S_i^r}(-g_{ij}^r-v_{ij}^r)s_{ij}^r,
 &B_r&=\sum_{i,j\in\mathcal S_i^r}(g_{ij}^r-g_j^r)s_{ij}^r.
 \label{eq:alignment-components}
\end{align}
\rev{$P_r$ is the alignment obtained if every pulse follows the current
local-update proxy. The correction $R_r$ subtracts twice the proxy magnitude
when retained memory makes a pulse oppose that proxy. The terms $L_r$ and
$B_r$ then account, respectively, for the mismatch between the multi-step
stochastic update and the current local gradient, and between the local and
global gradients.}

\begin{proposition}[Exact alignment decomposition]
For every realized round,
\begin{equation}
 A_r=P_r-R_r+L_r+B_r.
 \label{eq:alignment-decomposition}
\end{equation}
\end{proposition}
For each emitted pair, introduce the two intermediate quantities in separate
exact steps. First, adding and subtracting the local gradient gives
\begin{align*}
-g_j^rs_{ij}^r
&=-g_{ij}^rs_{ij}^r+(g_{ij}^r-g_j^r)s_{ij}^r.
\end{align*}
The second term is the client-to-global heterogeneity contribution. Next,
adding and subtracting the local-update proxy gives
\begin{align*}
-g_{ij}^rs_{ij}^r
&=v_{ij}^rs_{ij}^r+(-g_{ij}^r-v_{ij}^r)s_{ij}^r.
\end{align*}
Here $\vect{v}_i^r$ is the negative average stochastic gradient along the
local trajectory, so the second term measures its mismatch with the current
negative local gradient. Combining both steps yields
\begin{align*}
-g_j^rs_{ij}^r
&=v_{ij}^rs_{ij}^r+(-g_{ij}^r-v_{ij}^r)s_{ij}^r
 +(g_{ij}^r-g_j^r)s_{ij}^r.
\end{align*}
Finally, because $s_{ij}^r\in\{-1,+1\}$,
\begin{equation*}
v_{ij}^rs_{ij}^r
=|v_{ij}^r|-2|v_{ij}^r|\ind{s_{ij}^rv_{ij}^r<0}.
\end{equation*}
The factor two changes the nominal $+|v_{ij}^r|$ contribution into
$-|v_{ij}^r|$ when the pulse opposes the proxy. Summing over emitted pairs
therefore produces $P_r-R_r+L_r+B_r$ and proves
\eqref{eq:alignment-decomposition}. The terms isolate current-update
agreement, memory opposition, local mismatch, and heterogeneity. Since $L_r$
and $B_r$ have unrestricted signs, the identity alone cannot ensure alignment.

\begin{proposition}[\rev{One-round descent}]
If $F$ is $L$-smooth, the server update and the aggregate-norm bound give
\vspace{-3pt}
\begin{align}
 F(\vect{w}^{r+1})
 &\leq F(\vect{w}^r)+q_r\langle\nabla F(\vect{w}^r),\vect{C}^r\rangle
 +\frac{L}{2}q_r^2\norm{\vect{C}^r}_2^2 \notag\\
 &\leq F(\vect{w}^r)-q_rA_r+\frac{LM}{2}q_r^2N_r.
 \label{eq:descent}
\end{align}
\end{proposition}
\rev{This inequality holds pathwise. A stationarity result additionally
requires the emitted aggregate to align with global descent.}

\begin{theorem}[\rev{Conditional finite-horizon stationarity}]
\label{thm:conditional-stationarity}
\rev{Fix a horizon $R$ and assume that (i) $F$ is $L$-smooth and bounded below by
$F_{\inf}$, (ii) $\vect{w}^1$ and the positive schedule
$q_1,\ldots,q_R$ are deterministic, and (iii) there are constants $\kappa>0$
and deterministic $\beta_r\geq0$ such that
}
\begin{equation}
 \rev{\E[A_r\mid\mathcal{F}_r]\geq
 \kappa\norm{\nabla F(\vect{w}^r)}_2^2-\beta_r,}
 \label{eq:alignment-assumption-paper}
\end{equation}
\rev{where $\mathcal{F}_r$ contains all randomness revealed before the local
computation in round $r$. Define $Q_R=\sum_{r=1}^Rq_r$ and independently draw
$J_R$ with $\Pr(J_R=r)=q_r/Q_R$. Then}
\begin{align}
 {\color{blue}\E\norm{\nabla F(\vect{w}^{J_R})}_2^2}
 &\mathrel{\color{blue}\leq}
 {\color{blue}\frac{F(\vect{w}^1)-F_{\inf}}{\kappa Q_R}
 +\frac{\sum_{r=1}^Rq_r\beta_r}{\kappa Q_R}} \notag\\
 &\quad {\color{blue}+\frac{LM}{2\kappa Q_R}
 \sum_{r=1}^Rq_r^2\E N_r .}
 \label{eq:stationarity}
\end{align}
\end{theorem}

\rev{The first two assumptions are standard finite-horizon smoothness,
lower-boundedness, and scheduling conditions. The third is the learning-side
condition. It requires positive expected aggregate alignment up to the defect
$\beta_r$. The encoder guarantees state boundedness and an event budget, but it
does not guarantee this alignment. The theorem therefore states precisely what
follows when the optimization dynamics provide sufficient alignment.}

\rev{The three terms on the right of~\eqref{eq:stationarity} have distinct
roles. The first is the initial optimization gap divided by the cumulative
effective update mass $\kappa Q_R$. The second is the accumulated alignment
defect, averaged with the same $q_r$ weights used to select $J_R$. The third is
the smoothness cost of discrete event updates. It grows with the expected event
count $N_r$ and is weighted by $q_r^2$, so reducing the model quantum lowers
this curvature penalty. Consequently, a small bound requires enough cumulative
update mass, controlled alignment defects, and a quantum schedule for which the
event-curvature sum remains small relative to $Q_R$.}

\rev{Taking expectations in~\eqref{eq:descent} and applying
\eqref{eq:alignment-assumption-paper}, then dividing by $\kappa q_r$, yields}
\vspace{-3pt}
\begin{align*}
 \E\norm{\nabla F(\vect{w}^r)}_2^2
 &\leq \frac{\E F(\vect{w}^r)-\E F(\vect{w}^{r+1})}
 {\kappa q_r}+\frac{\beta_r}{\kappa}\\
 &\quad+\frac{LMq_r}{2\kappa}\E N_r.
\end{align*}
\rev{Multiplying this inequality by $q_r$ and summing over $r$ telescopes the
objective values. The lower bound $F\geq F_{\inf}$ and division by $Q_R$ then
give~\eqref{eq:stationarity}. Moreover,
$\E\norm{\nabla F(\vect{w}^{J_R})}_2^2=Q_R^{-1}\sum_rq_r
\E\norm{\nabla F(\vect{w}^r)}_2^2$. Thus, $J_R$ reports a
$q_r$-weighted random iterate for analysis without changing the algorithm or
claiming that the final iterate is best.}

At selected rounds, we \rev{independently rerun training from the same seed to
the audited round} and compute full client and global gradients after the event
decision. \rev{This diagnostic recomputation} evaluates $A_r$ and
\eqref{eq:alignment-decomposition} without altering training or later events.
For audited rounds $\mathcal A$, define
\begin{equation}
 \widehat\kappa_{\mathcal A}=
 \frac{\sum_{r\in\mathcal A}q_rA_r}
 {\sum_{r\in\mathcal A}q_r\norm{\nabla F(\vect{w}^r)}_2^2}.
 \label{eq:empirical-alignment-ratio}
\end{equation}
This normalized trajectory ratio compares realized first-order descent with
gradient energy. Positivity means average $q_r$-weighted alignment. It is
neither mean $A_r$ nor theoretical
$\kappa$ (only an analogue when $\beta_r=0$). \rev{It provides a descriptive
check of alignment along the recorded finite trajectories, but it cannot
establish the conditional expectation for unseen rounds or training runs in
\eqref{eq:alignment-assumption-paper}. Section~\ref{sec:results} therefore uses
the decomposition to explain observed mechanisms rather than to claim that the
assumption has been proved.}

\rev{We also assess the two empirical terms that correspond most directly to
the theorem. We retain the audit value $\kappa_0=8$, fixed before this
assessment, and define the realized defect
$\widehat\beta_r=[\kappa_0\norm{\vect{g}^r}_2^2-A_r]_+$. Over the audited
checkpoints $\mathcal A$, we report the zero-defect frequency and
\begin{equation}
 \widehat{\mathcal D}_{\mathcal A}
 =\frac{\sum_{r\in\mathcal A}q_r\widehat\beta_r}
 {\kappa_0\sum_{r\in\mathcal A}q_r},\qquad
 \widehat{\mathcal V}_{\mathcal A}
 =\frac{M\sum_{r\in\mathcal A}q_r^2N_r}
 {\sum_{r\in\mathcal A}q_r}.
 \label{eq:empirical-theorem-diagnostics}
\end{equation}
Here $\widehat{\mathcal D}_{\mathcal A}$ is the sampled analogue of the
alignment-defect term in~\eqref{eq:stationarity}. The observable
$\widehat{\mathcal V}_{\mathcal A}$ becomes the theorem's curvature term after
multiplication by $L/(2\kappa_0)$. We do not estimate a global smoothness
constant or substitute sampled checkpoints for the complete round sequence.
Thus these quantities diagnose the theorem's mechanism but are not presented
as a numerical convergence certificate.}

\section{Experimental Protocol}
\label{sec:experiments}

\textbf{Tasks and models.}
We evaluate ten-client image classification under strong label skew. The
Fashion-MNIST campaign uses a 25,818-parameter MLP for 150 rounds and a
14,538-parameter compact CNN for 80 rounds. \rev{Each Fashion-MNIST client
holds 6,000 examples: 3,300 from its designated dominant class and 300 from
each of the other nine classes. This preserves equal client sizes and global
class balance while giving every client a 55\% dominant-class fraction.}
CIFAR-10 uses a conventional
20,570-parameter CNN for 120 rounds. It has two strided convolutional layers with
8 and 16 channels, a 32-unit hidden layer, and a ten-class output. Each
CIFAR-10 client holds 5,000 examples: 2,750 from its dominant
class and 250 from every other class. All headline runs use ten active clients,
five local SGD steps, and minibatches of 32. The local learning rate is $0.1$ on
Fashion-MNIST and $0.05$ on CIFAR-10. \rev{For Event-FedAvg, every experiment
uses $r_0=100$ in the quantum schedule after~\eqref{eq:server-update}. The
decay exponent is $\alpha=0.1$ for the Fashion-MNIST MLP, $0.3$ for the
Fashion-MNIST CNN, and $0.2$ for the CIFAR-10 CNN.}
The corresponding frozen tuples
$(\rho,\vartheta,q_0,\alpha)$ are
$(0.999,0.025,0.005,0.1)$, $(0.999,0.025,0.010,0.3)$, and
$(0.999,0.025,0.005,0.2)$.
\rev{The ResNet-14 extension uses a 175,258-parameter group-normalized network
for 1,800 rounds with the same ten-client CIFAR-10 partition rule, five local
steps, learning rate $0.05$, and minibatch size 32. Its frozen Event-FedAvg
tuple is $(0.999,0.0125,0.005,0.3)$.}

\textbf{Practical parameter selection.}
For constant retention, $\rho$ sets an approximate encoder-memory horizon of
$1/(1-\rho)$ rounds. The threshold $\vartheta$ controls when coordinates fire
and hence the communication rate, whereas $q_0$ controls the server displacement
caused by each pulse. We therefore evaluate candidate $(\vartheta,q_0)$ pairs
on the development partition, select the pair with the lowest final training
loss, and freeze it before held-out evaluation. The exponent $\alpha$ controls
how quickly pulse-induced server updates shrink over the finite training
horizon. Although $\vartheta$ and $q_r$ have distinct roles, they are selected
jointly because the threshold changes both the number and timing of server
updates. The choice $\rho=0.999$ gives long evidence retention. The mechanism
audit below found no measurable difference from $\rho=1$ at the selected
finite-horizon operating point.

Across the broad comparison, EF-TopK uses
quality/nearest-traffic fractions $0.05/0.01$, while Strom uses thresholds
$0.00125/0.02$ on the Fashion-MNIST MLP, $0.005/0.02$ on the Fashion-MNIST
CNN, and $0.0025/0.01$ on CIFAR-10. \rev{The headline subset comprises the points
identified in Table~\ref{tab:main-results}. Its EF-TopK CIFAR-10 reference
uses class-wise fraction $0.05$, and its dense CIFAR-10 reference uses server
gain $\gamma=2$.}

\textbf{Selection and evaluation.}
We compare Event-FedAvg with dense FedAvg~\cite{mcmahan2017fedavg}, Sign-EF
based on sign quantization and error feedback
\cite{seide2014onebit,bernstein2018signsgd}, EF-TopK with memory
\cite{stich2018memory,richtarik2021ef21}, and Strom's residual-conserving
threshold pulses~\cite{strom2015distributed}. \emph{Matched local learning}
means identical client data, initialization, local steps, learning rate, and
minibatch order for every method sharing a seed. Only communication and its
server update differ.

Hyperparameters are selected on one development partition per benchmark. The
best-quality setting minimizes development training loss. For dense FedAvg,
the server gain $\gamma$ scales the usual aggregate as
$\vect{w}^{r+1}=\vect{w}^r+\gamma\sum_i p_i\vect{\delta}_i^r$. On CIFAR-10,
$\gamma=2$ is selected from $\{0.25,0.5,0.75,1,1.5,2,4\}$. For Strom and
EF-TopK, we also freeze the development setting closest to Event-FedAvg in log
total traffic. \rev{Table~\ref{tab:main-results} reports every configuration
included in the ten-seed extension. For each of these points, final values are
the mean and sample standard deviation over ten strong-skew partitions with
paired training seeds across methods. The extension reran the three original
seed pairs and seven additional pairs in one pinned campaign after all reported
method settings had been frozen. The subsequent
Figure~\ref{fig:communication-frontier} extension reran all remaining frozen
comparison settings on those same ten seed pairs.} Test
cross-entropy (CE), accuracy, worst-class accuracy, coordinate events, and
communication are recorded. No evaluation result influences development
selection.

\textbf{Communication metric.}
The primary metric, \emph{conservative bidirectional unicast traffic}, counts
uploads plus a separate downlink copy for every client, without a broadcast
discount. It includes headers, addresses, signs or values, initial
synchronization, \rev{a small per-round request, and the smaller of ordered
replay and a dense checkpoint. Dense model values are counted with the 32-bit
representation used in the experiments.} Applying one rule to every method prevents an omitted
downlink from making sparse communication appear artificially cheap.
\rev{Recomputing the headline points with one logical broadcast preserves every
reported Pareto direction. The corresponding traffic values are reported with
the results rather than used for model or hyperparameter selection.}

\textbf{Alignment factorial.}
On the Fashion-MNIST MLP, we run a full $2\times2$ factorial: every paired seed
is evaluated with either IID or strong non-IID client data and with either one
or five local steps, while all other Event-FedAvg settings remain fixed.
For each of ten paired partition and training seeds, rounds
$1,5,10,\ldots,150$ are
\rev{audited by independently rerunning the same seeded trajectory through the
chosen round.} Exact gradients use all 6,000 examples of every client
and are evaluated only after the audited event decision, preventing the
diagnostic computation from perturbing later threshold crossings.

Table~\ref{tab:main-results} makes the ten-seed tradeoffs explicit. On the
Fashion-MNIST MLP, Event-FedAvg gains $0.65$ points over the quality baseline
with $5.5\times$ less traffic and gains $4.23$ points over Strom at comparable
traffic. On the CNN, Strom gains $0.87$ points but uses $4.9\times$ more
traffic, whereas Event-FedAvg gains $2.14$ points at nearby traffic. On
CIFAR-10, Event-FedAvg leads tuned dense FedAvg by $4.25$ points using only
$12.7\%$ of its traffic and leads quality-selected Strom by $1.14$ points with
$4.6\times$ less traffic.

\rev{On ResNet-14, Event-FedAvg reaches $75.14\pm0.46\%$ accuracy and
$55.2\pm3.6\%$ worst-class accuracy using $21.04\pm0.19$ Gbit. Dense FedAvg
reaches $69.47\pm0.62\%$ and $47.6\pm5.2\%$, respectively, using $201.96$
Gbit. The paired Event-FedAvg accuracy advantage is $5.66$ points with a 95\%
interval of $[5.05,6.27]$ points and holds for all ten seed pairs. Thus the
architecture extension preserves the communication--accuracy benefit at
$10.4\%$ of dense traffic.}

\rev{Figure~\ref{fig:resnet-communication-trajectory} shows that this result is
not created only by the final checkpoint. The mean Event-FedAvg trajectory
reaches 65\% accuracy after approximately 9.31 Gbit, compared with 40.19 Gbit
for EF-TopK and 144.75 Gbit for dense FedAvg. Its advantage therefore develops
through the optimization trajectory, while the thin Strom curves expose
substantial seed sensitivity that its final mean alone would conceal. The
curves continue to improve late in training, so the plot supports a matched
finite-horizon efficiency comparison rather than a convergence claim.}

\rev{Looking only at the seven seed pairs whose outcomes were unavailable when
the configurations were frozen, every headline comparison keeps the same
direction as in the full ten-seed summary.} Event-FedAvg minus the quality baseline is $+0.69$, $-0.86$, and
$+1.14$ points on the MLP, Fashion-MNIST CNN, and CIFAR-10, respectively. The
95\% paired intervals are $[0.25,1.12]$, $[-1.66,-0.05]$, and $[0.09,2.19]$.
Table~\ref{tab:main-results} reports all ten seeds.

\rev{A separate three-seed ablation tests which encoder choices matter at the
selected CIFAR-10 operating point.} Removing leakage
($\rho=1$) \rev{produces nearly the same result as} the frozen setting at this resolution
($48.32\pm1.05\%$ versus $48.25\pm1.07\%$). Coupling the quantum and trigger
at $0.025$ instead reduces accuracy to $18.42\pm7.33\%$. This supports their
independence for the selected operating point, not a universal claim that every
coupled schedule fails.

Table~\ref{tab:alignment-factorial} reports ten seeds and \rev{31 diagnostic
checkpoints per seed: rounds $1,5,10,\ldots,150$. For each checkpoint, training
is rerun from the same initialization and seed only to compute the audit
quantities. These are not 31 additional rounds in one training run and are
unrelated to ordered downlink replay.} Its
$\widehat\kappa_{\mathcal A}$ is the trajectory ratio in
\eqref{eq:empirical-alignment-ratio}, not mean $A_r$ or the theoretical
$\kappa$. The next columns separate positive first-order alignment, realized
descent, and their disagreement.

$\overline B_{\mathcal A}$ exposes the adverse heterogeneity contribution.
$\overline L_{\mathcal A}$ shows that \rev{increasing the number of local SGD
steps per round from one to five} acts differently under IID
and non-IID data, so the terms interact rather than form independent penalties.
The final column is the remainder after the first-order change. With strong
non-IID data, \rev{five local SGD steps per round} keep frequent positive alignment but yield
fewer objective decreases and a larger remainder. No emitted pulse opposes the
current local-update proxy in the $1{,}240$ snapshots, \rev{so the recorded
memory-opposition term is exactly zero at every audited checkpoint. This is an
empirical statement about the recorded checkpoints, not a general property of
the encoder.} This explains
a finite-step heterogeneity--depth limitation without establishing the
conditional expectation in~\eqref{eq:alignment-assumption-paper}.

\rev{The theorem-facing diagnostic gives the same qualified picture. For
$\kappa_0=8$, the zero-defect inequality holds at
$87.7\pm2.0\%$, $91.9\pm3.8\%$, $92.3\pm1.7\%$, and
$93.5\pm3.4\%$ of checkpoints in the IID $E=1$, IID $E=5$, strong non-IID
$E=1$, and strong non-IID $E=5$ cells. The corresponding
$\widehat{\mathcal D}_{\mathcal A}$ values are
$0.063\pm0.002$, $0.021\pm0.001$, $0.029\pm0.004$, and
$0.022\pm0.003$. Hence occasional poorly aligned rounds are captured by a
nonzero defect instead of being hidden by the positive trajectory average.
The observable event-curvature factors $\widehat{\mathcal V}_{\mathcal A}$
are $20.0\pm0.6$, $83.7\pm1.9$, $158.1\pm4.3$, and
$306.6\pm4.6$, respectively. Their increase with non-IID data and five local
steps is consistent with the observed gap between positive first-order
alignment and actual objective descent. These are sampled trajectory
diagnostics, not estimates of the conditional expectation or the unknown
global smoothness constant.}

\rev{Event-FedAvg does not outperform every comparator on every predictive
metric.} On CIFAR-10, Event-FedAvg
has $26.0\pm4.0\%$ mean worst-class accuracy and frozen EF-TopK has
$24.9\pm1.9\%$. Their paired difference is $+1.16$ points with a 95\% interval
$[-1.72,4.04]$, so these data do not resolve a class-wise advantage. Together
with the alignment audit in Section~\ref{sec:theory}, the results support the
proposed finite-horizon communication mechanism. \rev{They do not prove
Assumption~\eqref{eq:alignment-assumption-paper}, because the audit measures
realized alignment at finitely many checkpoints, whereas the assumption is a
conditional-expectation statement required across the learning process.}

\section{Limitations}
\label{sec:limitations}

\rev{The present evaluation focuses on synchronous full participation with ten
clients and two image datasets. The communication--performance comparisons use
ten paired seeds per reported setting, including seven seed pairs added only
after the configurations were frozen. The resulting paired intervals quantify
variation across these ten matched runs. They do not correct simultaneously for
all comparisons or for the fact that the headline configurations originated
from an earlier development and pilot process. The factorial audit likewise
uses ten seeds and deliberately varies only data partitioning and the number of
local SGD steps around one Fashion-MNIST operating point. Broader datasets,
architectures, participation patterns, and hyperparameter regimes remain to be
evaluated. The theoretical result makes aggregate alignment an explicit
condition rather than proving it for the coupled learning dynamics, and the
finite-horizon quantum schedules are not used to claim asymptotic convergence.
Finally, communication is evaluated through reproducible software-level bit
counts under exact synchronization. Latency, packet loss, asynchronous
execution, and hardware energy require system-level experiments.}

\section{Conclusion}
\label{sec:conclusion}

Event-FedAvg turns temporally accumulated local-update evidence into sparse
signed events using leakage, full reset, and a trigger-independent model
quantum. The complete protocol includes the downlink required for exact client
synchronization. Pathwise guarantees cover encoder state and event count, while
alignment remains the explicit optimization condition. Event-FedAvg is
nondominated in the evaluated synchronous ten-client settings. The audit shows
that quantum decoupling matters for the selected configuration, leakage at
$\rho=0.999$ has no measurable isolated effect, and heterogeneity can turn
positive first-order alignment into non-descent. These findings sharpen both
the contribution and its boundary. \rev{The seven seed pairs added after
configuration freezing preserve the directions observed in the original
three-seed results, and the separate ten-seed ResNet-14 extension preserves the
communication--accuracy benefit on a deeper architecture. Next experiments
should target partial participation and measured communication systems.}
